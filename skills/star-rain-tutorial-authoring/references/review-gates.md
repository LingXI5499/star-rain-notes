# 章节审核门禁

## 结构与边界

- 明确读者、学习目标、主题版本或条件、已有前置与本章边界。
- 星雨笔录默认章节只有 `title`、`summary` 元数据，正文不重复页面标题与摘要，四个 H2 按顺序出现；用户自定义结构按其要求检查。
- H3 表示真实知识点、问题类别或练习类型，与父级编号一致；H4 只用于独立子知识，不跨父级。
- 没有机械重复定义、语法、示例等模板标题，也没有重复总结或提前展开后续章节。

## 相关性与表达

- 核心知识具有明确的学习依赖、实际应用或关键边界价值；按课程目标判断，不强制所有教程服务求职或编程。
- 新特性和便利工具不因“存在”就进入主线；领域参考只适用于相应主题与条件。
- 示例形式匹配主题：语言/API 可以写代码，操作教程写步骤与预期结果，原理可写关系与推导，非编程知识可用案例或材料。
- 代码完整且聚焦当前知识，注释解释意图与易错点。多项对比适合表格，流程适合步骤，提醒对应真实风险或关键混淆。

## 证据与训练

- 需求依据与事实依据分开；重要结论有适用版本或学科的可追溯来源。
- 验证方式匹配示例：代码运行、命令执行、操作检查或计算核对；故意错误的示例明确标注。
- 未验证项如实记录；格式通过不等于技术正确，资料查证不等于执行成功。
- 问题与练习覆盖学习目标，并给出能核对的结果或判断标准，不要求未学内容。

存在结构、事实、目标映射错误，或承诺可复现的关键示例仍待验证时标记 `REVISE`，列出具体待办。任务范围内的检查完成后可标记 `READY_FOR_HUMAN_REVIEW`，附上证据及未执行项；该状态不表示人工批准或自动发布。
