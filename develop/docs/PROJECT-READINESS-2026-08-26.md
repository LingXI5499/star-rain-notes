# 星雨笔录上线就绪审计（2026-08-26）

## 结论

项目已进入“生产部署与真实外部服务验收”阶段。核心前后台、账号协作、内容模块、英语学习、媒体、搜索和部署制品均已具备；代码级发布门槛已通过。仍需在目标阿里云服务器完成 DNS/HTTPS、163 SMTP 实收信、首次激活、邀请注册、备份恢复和 30 分钟资源观察，完成后才能认定生产上线闭环。

## 已验证范围

- 后端：306 项测试全部通过，覆盖数据库迁移/约束、Session/CSRF、账号权限、管理员即时失效、教程、博客、作品、站点、搜索、媒体、词汇及英语各模块。
- 前端：TypeScript 类型检查和 Vite 生产构建通过。
- 真实浏览器：主页、教程、博客、作品、英语、词汇、关于、搜索、教程章节、登录及旧 Setup 路由完成冒烟；控制台无 warning/error。
- 响应式：390、1024、1440 三档关键页面无横向溢出。
- 运行链路：Vite `/api` 代理、健康检查、公开 API、CSRF、未登录 401 均符合预期。
- 生产配置：打包 JAR 以 `prod` 启动成功，只监听 `127.0.0.1`；旧 Setup 返回 410；Swagger/OpenAPI 返回 404。
- 部署脚本：备份和健康脚本通过 `bash -n`，部署文件强制 LF 行尾。

## 本轮可靠性修复

- 测试上下文固定使用 `test` profile，避免误连本地开发库。
- 新增生产旧 Setup/旧用户名登录禁用测试。
- 登录轮换 Session ID；密码修改只能作用于当前账号。
- 管理员禁用或凭据版本变化后，现有 Session 下一次请求立即失效。
- 邮箱验证码与邀请记录绑定，避免跨邀请误用。
- 测试数据库配置改为 `TEST_MYSQL_*` 可覆盖，不保存生产凭据。
- 扩充 `.gitignore`，隔离密钥、构建产物、依赖和运行时上传文件。
- 备份增加互斥锁、临时文件、原子改名、压缩校验、磁盘阈值、低权限 MySQL 兼容选项。
- 健康脚本增加公开链路、权限边界、生产入口、安全头和缓存头检查。
- 修复上传目录权限模型；JAR/环境文件移出 Web 根目录。
- systemd 环境文件改为硬依赖，移除无效 HUP 热重载，增加资源约束和安全加固。

## 性能调整

- 账号 Session 校验仅查询主键对应的 `account_status` 与 `auth_version`，不再读取整行及密码哈希。
- 认证 Store 改为进入后台路由时动态加载，公共壳不再提前包含账号会话逻辑。
- 生产 Tomcat、Hikari 与 JVM 按 2 核 2 GB ECS 设定有界资源参数。
- Nginx 启用上游 keepalive、响应缓冲、gzip、静态文件缓存、open file cache 和哈希资源一年 immutable 缓存。

## 上线前仍需人工完成

1. 阿里云安全组仅开放 22（限管理员 IP）、80、443 和宝塔面板端口（限管理员 IP）。
2. 根域名与 `www` 的 A 记录解析到 ECS，ICP/公安备案符合要求。
3. MySQL 8.0 本地库、生产环境文件权限和 163 SMTP 授权码配置完成。
4. 超级管理员真实邮件激活、忘记密码、邀请注册与重新邀请完成实收信测试。
5. HTTPS 证书自动续签、HTTP 301、HSTS、上传媒体读取与外网 24680/3306 不可达验证通过。
6. 自动备份成功，并实际恢复到临时库一次。
7. 发布后观察至少 30 分钟：无持续 5xx、连接池耗尽或 Java RSS 持续增长。
