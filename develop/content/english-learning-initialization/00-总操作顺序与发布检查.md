# 总操作顺序与发布检查

## 一、开始前确认

1. 使用超级管理员账号登录后台。
2. 打开“英语管理 → 标签管理”，确认能看到 TOPIC、SCENE、FUNCTION、ABILITY、GENRE、FORMAT 六个维度。
3. 不创建同名标签。本套内容只使用数据库已初始化的标签。
4. 打开“媒体库”，确认可以上传 `AUDIO` 类型文件。
5. 浏览器只保留一个后台编辑标签页，避免重复保存。

## 二、严格录入顺序

### 阶段 1：公共信息

1. 在“英语管理 → 总览设置”填写总览。
2. 在“标签管理”核对已有标签，但不新增、不改名、不禁用。

### 阶段 2：阅读

每个等级依次执行：

1. 新建文章并保存为草稿。
2. 创建两道练习，练习状态选“已发布”。
3. 返回阅读列表发布文章。
4. 打开前台详情，实际作答一次并核对解析。

阅读发布必须具备标题、摘要、正文、CEFR、能力层级、至少一个主题标签和一个文体标签。

### 阶段 3：听力

1. 根据听力文档制作 MP3。
2. 在媒体库上传并确认类型为 `AUDIO`。
3. 新建听力材料，选择音频并保存。
4. 再次进入编辑页，按真实音频建立逐句片段。
5. 创建两道听力练习。
6. 关联同等级阅读文章。
7. 最后发布听力材料。

不要在没有实际音频的情况下猜测时间片段。所有 `startMs`、`endMs` 都以播放器实测为准，并满足：

```text
0 <= startMs < endMs <= 音频总时长（秒）× 1000
```

### 阶段 4：语音规则

按连读、弱读、同化、省音、重音、语调的顺序创建。短示例音频可使用对应文档中的脚本生成，上传后再选择。

### 阶段 5：写作

1. 先建立并发布 6 个“学习资源”。
2. 再建立 6 个“写作任务”。
3. A2 任务关联 A2 模板；B1、C2 任务关联对应范文。
4. 为每个任务创建一道已发布练习。
5. 发布任务。

模板或范文未发布时，引用它们的写作任务无法发布。

### 阶段 6：词族与学习组合

1. 创建 6 个词族，关联文档给出的现有单词 ID。
2. 确认阅读、听力、写作任务均已发布。
3. 创建 A1–C2 六个学习组合。
4. 每个组合按“阅读 → 听力 → 写作”排列后发布。

组合发布必须满足：有摘要、有主 CEFR、至少两项内容、覆盖至少两个模块，且组合内内容全部已发布。本方案统一使用三个模块。

## 三、状态处理

| 当前状态 | 正确操作 |
|---|---|
| DRAFT | 补齐内容后点击“发布” |
| PUBLISHED | 修改前先确认账号权限；普通管理员修改会提交审核 |
| WITHDRAWN | 检查内容后点击“重新发布” |

删除已发布的阅读、听力或写作内容前，必须先撤回。学习组合依赖的内容不要直接删除。

## 四、每条内容的发布前检查

- [ ] 标题、摘要和正文完整。
- [ ] CEFR 与能力层级符合文档。
- [ ] 标签维度选择正确。
- [ ] JSON 能被后台保存，没有中文引号和尾随逗号。
- [ ] 标准答案与解析一致。
- [ ] 内容编号由系统生成，没有手工修改。
- [ ] 听力音频可播放，片段没有重叠或越界。
- [ ] 来源和版权信息已填写。
- [ ] 前台详情可打开并能完成练习。

## 五、常见错误

| 提示或现象 | 处理方法 |
|---|---|
| 至少需要主题或文体标签 | 回到编辑页选择正确维度的已启用标签并保存 |
| 音频资源不能为空 | 先在媒体库上传音频，再在听力编辑页选择 |
| 存在非法时间片段 | 检查毫秒值、先后顺序和音频总时长 |
| Exercise config invalid | 检查 JSON 结构、答案键和数组格式 |
| 模板必须已发布 | 先发布写作模板，再发布引用它的任务 |
| 组合中的内容未发布 | 打开组合工作区，找出草稿或已撤回条目 |
| 普通管理员保存后前台未变化 | 到审核中心由超级管理员批准 |
