# 英语总览与现有标签使用

## 一、总览设置

后台入口：`英语管理 → 英语工作台 → 总览设置`

### 标题

```text
英语能力成长路径
```

### 副标题

```text
从可理解输入到清晰表达，按 CEFR 建立阅读、听力与写作的长期学习闭环。
```

### 介绍

```text
这里不是零散资料的集合，而是一条从 A1 到 C2 的能力成长路线。每个等级都以一个真实主题串联阅读、听力和写作：先理解信息，再辨认真实语流，最后用自己的语言完成表达。学习者可以通过练习检查理解，通过学习记录观察进度，并在同级学习组合中依次完成输入、加工与输出。
```

### 路线图（Markdown）

```markdown
## 如何使用这套内容

每个等级都建议按以下顺序学习：

1. **精读文章**：理解主题、结构和关键表达。
2. **完成阅读练习**：检查事实理解、逻辑关系与推断能力。
3. **收听同主题材料**：先盲听，再结合逐句文本复听。
4. **完成听力练习**：定位信息、判断态度并训练真实语流识别。
5. **学习写作资源**：掌握当前等级需要的句子、段落或文体方法。
6. **完成写作任务**：把输入转化为自己的表达。

## 六级路线

- **A1 · 日常生活**：使用简单句说明时间、地点和个人计划。
- **A2 · 出行情境**：理解实用信息，提出问题并写出简短邮件。
- **B1 · 健康与科技**：叙述习惯、解释原因并提出可执行的改变。
- **B2 · 工作与协作**：比较方案、组织建议并处理不同观点。
- **C1 · 科技与教育**：分析复杂问题，建立平衡而清晰的论证。
- **C2 · 治理与伦理**：识别隐含立场，处理责任边界与价值冲突。

## 学习原则

- 第一次阅读或收听时先抓主旨，不急于查每个词。
- 第二次学习时记录影响理解的表达和逻辑连接。
- 做完练习后阅读解析，并回到原文寻找证据。
- 写作完成后使用任务自检清单修改一次，再保存最终稿。
- 学习记录用于观察趋势，不追求一次完成所有内容。
```

保存后打开前台英语首页，确认标题、副标题、介绍和路线图正常显示。

- 学习场景：B1、C1。

- 短对话：A1。

- 独白：B1。
- 演讲与讲座：C1。
- 新闻听力：C2。

### GENRE · 文体（5）

- 应用文本：A1、A2。
- 说明文：B1、B2。
- 议论文：C1。
- 学术文本：C2。
- 新闻报道：可用于 C2 的补充标签。

### ABILITY · 能力（12）

`句子理解、信息提取、主题句识别、结构分析、指代判断、逻辑判断、隐含推断、语音识别、信息保持、观点组织、衔接连贯、风格控制`

### FUNCTION · 功能（9）

`描述、说明、比较、举例、因果、转折、论证、反驳、总结`

## 三、禁止的操作

- 不修改上述标签名称或原有编号。
- 不为了一个内容创建近义重复标签。
- 不禁用已被内容引用的标签。
- 不把 SCENE 标签放进阅读主题字段，也不把 GENRE 标签放进听力形式字段。
