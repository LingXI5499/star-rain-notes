# 英语后台完整操作流程与排错

本文以修复后的管理后台为准。建议先用超级管理员完成第一轮录入和发布，再用普通学习账号验证前台学习记录。文档中的正文和题目内容分别复制自 `01`—`07` 文件，本篇负责说明页面入口、字段关系、保存顺序和错误处理。

## 一、部署后先做基础检查

1. 登录 `https://yulanlin.cn/admin`。
2. 打开“英语管理 → 英语工作台”，确认阅读、听力、写作、语法等入口可见。
3. 打开“英语管理 → 标签管理”，确认既有 49 个标签存在。本轮不要重复创建同名标签。
4. 打开“媒体库”，上传一个小于 5 MB 的 MP3 测试文件并在媒体库直接播放。
5. 若媒体库不能播放，暂停内容录入，先按升级文档检查 `/uploads/`。数据库里存在媒体记录并不代表磁盘文件可以通过 Nginx 访问。

## 二、标签选择的统一方法

阅读、听力和写作表单中的标签选择方式相同：

1. 在“搜索并选择标签”中输入中文名称或编号。
2. 点击搜索结果。
3. 搜索框会自动清空，所选项出现在上方的标签胶囊中。
4. 已选标签不会继续出现在候选结果中。
5. 如选错，点击标签胶囊右侧的 `×` 移除，不需要删除搜索框文字。

发布要求：

- 阅读：按页面发布检查填写主题、文体和正文等内容。
- 听力：SCENE 场景和 FORMAT 形式各至少一个。
- 写作：TOPIC 主题或 GENRE 文体至少一个。

## 三、阅读管理

入口：`英语管理 → 阅读管理`。

1. 点击“新建文章”。
2. 按 `02-A1-C2阅读内容与练习.md` 填写标题、摘要、正文、CEFR、能力层级、来源和版权。
3. 选择主题、文体、能力等标签。
4. 保存文章。
5. 返回列表进入“练习”，每篇录入两道题，确保配置 JSON 可以保存并设为已发布。
6. 超级管理员点击文章“发布”。
7. 点击“预览”，确认正文、目录、标签和练习均能打开。

如果保存成功但发布失败，优先阅读页面提示的具体缺失字段，不要反复点击发布。

## 四、听力管理

入口：`英语管理 → 听力管理`。

### 4.1 三种内容的关系

- **完整音频**：一整段对话或独白，只上传一个 MP3、M4A 或 OGG 文件。
- **完整听力稿与学习说明**：用 Markdown 保存完整英文稿、重点表达和学习建议。
- **逐句时间片段**：每条记录对应完整音频中的一段时间，包含开始时间、结束时间、英文原文和可选中文翻译。前台使用这些片段进行字幕高亮和点击定位。

不要把每句话分别上传成多个音频。

### 4.2 正确录入顺序

1. 点击“新建材料”。
2. 填写标题、摘要、完整听力稿、CEFR、能力层级、来源与版权。
3. 点击“上传或选择音频”，可以在弹窗内直接上传；上传后先试听。
4. 音频加载成功后，系统自动读取并填写完整时长。
5. 选择至少一个场景标签和一个形式标签，再选择主题、能力或功能标签。
6. 点击“保存基础信息”。新建成功后页面会停留在当前材料，不会返回列表。
7. 播放完整音频。到达一句开始位置时点击片段的“取播放器时间”；到达结束位置时再次取时间。
8. 时间格式为 `00:00:00.000`。填写该段英文原文和中文翻译。
9. 依次添加全部片段，保证按播放顺序排列且不重叠，然后点击“保存全部片段”。
10. 在右侧选择同级已发布阅读并建立“同主题”等配对。
11. 返回听力列表进入“练习”，按 `03-A1-C2听力内容与音频制作.md` 每篇录入两道已发布练习。
12. 打开“发布检查”；全部通过后，由超级管理员在列表发布。

### 4.3 音频错误含义

- “音频无法加载”：通常是 `/uploads/` alias、文件权限或磁盘文件位置错误。
- 浏览器返回 `404`：数据库记录存在，但 Nginx 指向的目录中没有该文件。
- 浏览器返回 `403`：Nginx 用户没有读取目录或文件的权限。
- 能下载但无法拖动：服务器没有正确处理 Range 请求，使用升级验收命令检查是否返回 `206`。
- 仅某个文件失败：检查扩展名、MIME 和文件本身是否能被普通播放器打开。
- “片段重叠”：后一段开始时间小于前一段结束时间；修改时间后再批量保存。

## 五、语音规则

入口：`英语管理 → 语音规则`，也可以在听力管理顶部点击“语音规则”。这是已经存在的独立内容模块，并非听力材料中的标签。

1. 点击“新建规则”。
2. 从连读、弱读、同化、省音、重音、语调中选择一种类型。
3. 按 `04-六类语音规则课程.md` 填写标题、摘要和 Markdown 正文。
4. 可上传一段短示例音频；选择音频后必须先试听成功。
5. 填写排序并保存。
6. 打开“发布检查”，确认标题、摘要和正文齐全。
7. 超级管理员发布；普通管理员只负责编辑并等待超级管理员操作。

## 六、写作管理

入口：`英语管理 → 写作管理`。页面分“学习资源”和“写作任务”两个标签。

### 6.1 先创建学习资源

资源类型包括表达训练、文体课程、范文和模板：

1. 点击“新建资源”。
2. 填写标题、摘要、正文、CEFR、词数、预计时间、排序和可选封面。
3. 表达训练需选择句子、段落、衔接或风格层级。
4. 模板通过“模板填写区块”逐项增加，不需要手写 JSON：
   - 区块编号只用小写字母、数字和连字符，例如 `opening`、`main-point`。
   - 选择单行或多行文本。
   - 设置显示名称和是否必填。
5. 选择主题或文体标签，必要时补充功能和能力标签。
6. 打开发布检查，保存后由超级管理员发布。

模板和范文必须先发布，才能被写作任务关联。

### 6.2 再创建写作任务

1. 切换到“写作任务”，点击“新建任务”。
2. 填写标题、摘要、真实写作背景、明确写作要求、CEFR、词数和预计时间。
3. 可从下拉框选择已经发布的写作模板和范文。
4. 评分标准逐项填写名称和最大分值，总和不得超过 100。
5. 自检清单逐项填写一句可执行的检查要求。
6. 选择至少一个主题或文体标签，选择封面和排序。
7. 发布检查通过后保存。
8. 返回列表进入“练习”，按 `05-A1-C2写作资源任务与练习.md` 新增并发布练习。
9. 最后发布写作任务。

常见失败：

- “至少需要主题或文体标签”：没有选择 TOPIC 或 GENRE。
- “模板必须已发布”或“范文必须已发布”：先发布关联资源，再发布任务。
- “Rubric total cannot exceed 100”：评分项总分超过 100。
- 表单编辑后封面消失：新版已修复；保存请求会保留当前封面、模板和范文 ID。

## 七、词族管理

入口：`英语管理 → 词族管理`。

1. 按 `06-A1-C2词族填写.md` 查找现有主词 `use`、`travel`、`decide`、`create`、`analyze`、`govern`。
2. 新建词族时关联已有主词，不要重复创建主词库词条。
3. 依次添加派生词、词性、音标、CEFR、释义和真实例句。
4. 使用上下移动调整成员顺序。

## 八、学习组合

入口：`英语管理 → 学习组合`。

1. 新建组合，填写标题、摘要和主 CEFR。
2. 点击“编排学习路径”。
3. 从内容库依次加入同级的一篇已发布阅读、一个已发布听力和一个已发布写作任务。
4. 调整顺序为“阅读 → 听力 → 写作”。
5. 检查条应分别显示阅读、听力、写作数量至少为 1，且所有引用内容均为已发布。
6. 超级管理员发布组合。发布后路径锁定，需要调整时先撤回。

历史上已经发布但不足三个模块的组合不会被自动删除或撤回，后台会显示“历史组合待补全”。一旦撤回，重新发布前必须补齐三类内容。

## 九、完整学习验收

使用普通学习账号执行：

1. 打开一个学习组合。
2. 完成阅读并提交练习，确认判分与解析正常。
3. 播放听力，点击字幕片段确认能跳转，高亮随播放变化；提交听力练习。
4. 打开写作任务，查看模板和范文，完成练习并提交一次真实作文。
5. 返回学习进度页，确认阅读、听力和写作记录存在。
6. 使用超级管理员打开“英语管理 → 学习分析”，确认产生真实学习数据。

## 十、建议的逐级录入顺序

每个 CEFR 等级都按以下顺序完成，避免引用尚未发布的内容：

1. 阅读文章 → 阅读练习 → 发布阅读。
2. 完整音频 → 听力材料 → 时间片段 → 阅读配对 → 听力练习 → 发布听力。
3. 写作资源/模板/范文 → 发布资源 → 写作任务 → 写作练习 → 发布任务。
4. 词族。
5. 阅读 + 听力 + 写作学习组合 → 发布组合。
6. 用学习账号完成该等级的一次端到端测试，再开始下一级。
