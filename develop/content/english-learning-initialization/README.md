## 统一填写约定

- 内容编号由后端自动生成，不填写 slug。
- 未指定排序时保持系统自动追加；需要手动填写时按 `10、20、30……`。
- 阅读、听力来源名称：`星雨笔录原创`。
- 来源地址：留空。
- 版权说明：`星雨笔录原创学习内容，仅供本站学习使用。`
- 封面：本轮可留空。
- 正文中的 Markdown 标题从 `##` 开始，不再添加页面级 `#` 标题。
- 题目配置必须复制完整 JSON，不能使用中文引号或在 JSON 后追加注释。
- 普通管理员修改已发布内容会进入审核；超级管理员负责批准、发布和撤回。
- 听力材料使用“一份完整音频 + 完整听力稿 + 多个逐句时间片段”的结构；片段不是独立音频。
- 学习组合发布前必须同时包含至少一项已发布阅读、听力和写作任务。
