# A1–C2 学习组合发布与全链路验收

学习组合是本轮最后录入的内容。只有阅读、听力和写作任务均已发布后，才开始创建组合。

后台入口：`英语管理 → 英语工作台 → 学习组合`（页面标题“跨模块学习路径”）。内容编号由系统自动生成，封面可留空。

## 一、发布前依赖检查

每个等级先确认：

- 阅读文章已发布，并且 2 道阅读练习均为 `PUBLISHED`。
- 听力材料已上传真实音频、填写实际毫秒片段并发布，2 道听力练习均为 `PUBLISHED`。
- 听力材料已经关联同级阅读文章。
- 写作任务已发布，量表与清单能正常显示，1 道写作练习为 `PUBLISHED`。
- A2、B1、C2 写作任务引用的模板或范文已经先发布。

组合内容库默认筛选“已发布”。如果搜索不到某项内容，先回到对应模块检查发布状态，不要为了绕过检查创建同名内容。

## 二、六个组合的填写内容

### A1 · 在社区图书馆安排一天

- 标题：A1 日常英语：在社区图书馆安排一天
- 摘要：先读懂图书馆日程，再听两位朋友确认见面安排，最后用简单句写出自己的到达时间、活动和离开时间。
- 主要 CEFR：`A1`
- 排序：`10`
- 封面：留空

按顺序加入：

1. `READING` — A Day at the Community Library
2. `LISTENING` — Meeting at the Library
3. `WRITING` — 写下我的图书馆日程

学习结果：学习者能够从短文本和短对话中提取时间、地点和活动，并用 30–60 词说明个人日程。

### A2 · 计划一次周末火车旅行

- 标题：A2 出行英语：计划周末火车旅行
- 摘要：阅读出行计划、收听列车选择对话，再使用礼貌邮件模板询问车次、票价和订座信息。
- 主要 CEFR：`A2`
- 排序：`20`
- 封面：留空

1. `READING` — Planning a Weekend Train Trip

学习结果：学习者能够比较基本出行选项，识别关键时间与价格信息，并写出 60–120 词的礼貌咨询邮件。

## 三、后台具体编排与发布

每个组合重复以下操作：

1. 点击“新建组合”，填写标题、摘要、主要 CEFR 和排序，保存。
2. 在组合卡片点击“编排路径”。
3. 内容库状态保持“已发布”，CEFR 选择当前级别。
4. 类型选择“阅读”，搜索本页指定的英文标题，点击“加入”。
5. 类型选择“听力”，搜索指定标题并加入。
6. 类型选择“写作”，搜索指定的中文任务标题并加入。这里的 `WRITING` 指写作任务，不是写作资源。
7. 在右侧路径中通过拖拽或上下按钮调整为“阅读 → 听力 → 写作”。
8. 发布检查应显示：`3 项内容`、`3 个模块`、全部已发布，且无待处理项。
9. 超级管理员点击“发布路径”并确认。发布后路径锁定；需要修改时先撤回。
10. 点击组合卡片的“预览”，用普通学习账号检查三项内容链接。

## 四、普通学习账号真实链路测试

建议从 A1 开始完整做一次，再对 A2–C2 做页面与判分抽查。不要用管理员账号代替学习账号，否则无法确认普通用户权限和个人记录链路。

### 1. 总览与筛选

- 打开英语首页，确认“英语能力成长路径”、副标题和六级路线正常显示。
- 依次选择 A1、A2、B1、B2、C1、C2。
- 每级应至少看到 1 篇阅读、1 个听力、1 个写作资源、1 个写作任务和 1 个学习组合。
- 页面不应要求用户手工理解数字编号；标题、摘要和 CEFR 是主要识别信息。

### 2. 阅读链路

以 A1 文章 `A Day at the Community Library` 为完整测试对象：

1. 打开文章，确认正文、主题“社会”、文体“应用文本”和 CEFR A1。
2. 完成两道阅读题，一题故意答错、一题答对。
3. 提交后确认系统给出判分结果和中文解析，不向前端提前暴露标准答案。
4. 返回列表后重新进入，确认页面仍为 HTTP 200。
5. 对 A2–C2 各打开一篇，并各提交至少一道题，检查不同题型均可操作。

### 3. 听力链路

以 A1 材料 `Meeting at the Library` 为完整测试对象：

1. 首次不看文本播放完整音频，确认可开始、暂停和拖动进度。
2. 再查看逐句片段，逐条点击时应从对应实际毫秒位置播放。
3. 检查英文句子与中文翻译对应，最后一个片段不超出音频时长。
4. 完成两道听力题，确认判分与解析。
5. 检查“关联阅读”能打开 `A Day at the Community Library`。
6. 对 A2–C2 各播放开头、中间、结尾三个位置，排除空音频、截断或文件关联错误。

### 4. 语音规则链路

- 打开语音规则列表，应有连读、弱读、同化、省音、重音、语调 6 条。
- 每条详情正文能打开；如果上传了短音频，播放器对应本条规则。
- 在“句子重音”和“语调”课程中完成一次录音跟读，并人工比较焦点或句尾音高。

### 5. 写作链路

以 A2 任务 `写一封周末列车咨询邮件` 为完整测试对象：

1. 打开任务，确认字数范围为 60–120，能看到已发布的旅行邮件模板。
2. 按模板写一封不含敏感信息的邮件。
3. 对照自检清单修改一次，完成任务内练习。
4. 保存或提交后刷新页面，确认草稿或提交结果没有丢失。
5. 打开 B1、C2 任务，确认分别能引用指定范文。
6. 对其他等级检查字数上下限、评分量表总分和任务说明。

### 6. 学习组合链路

- 打开六个组合，每个都恰好有 3 项内容、覆盖 3 个模块。
- 内容顺序固定为阅读、听力、写作。
- 从 A1 组合依次进入三项并返回组合，确认导航没有失效。
- 组合中的所有内容 CEFR 与组合主要 CEFR 一致。

### 7. 学习记录、推荐与分析

1. 普通学习账号至少完成一次阅读答题、一次听力答题和一次写作保存或提交。
2. 打开个人学习记录，确认出现对应标题、内容类型和发生时间。
3. 查看英语首页或推荐区域；如果系统有足够行为后产生推荐，确认链接能打开。没有推荐时先确认记录是否真正提交，不人为插入推荐数据。
4. 切换到管理员账号，进入 `英语管理 → 学习分析`。
5. 选择包含测试日期的时间范围，分别筛选“全部、阅读、听力、写作”。
6. 核对模块计数和最近活动来自刚才的真实操作；不要直接修改数据库制造统计。

## 五、公开接口检查

在宝塔终端执行以下只读命令。列表接口返回 `200` 且对应级别有数据；详情地址需用后台列表显示的实际数字编号替换 `{编号}`。

```bash
curl -fsS -o /dev/null -w 'meta %{http_code}\n' 'https://yulanlin.cn/api/v1/public/english/meta'
curl -fsS -o /dev/null -w 'reading-A1 %{http_code}\n' 'https://yulanlin.cn/api/v1/public/english/reading/articles?page=1&pageSize=20&cefr=A1'
curl -fsS -o /dev/null -w 'listening-A1 %{http_code}\n' 'https://yulanlin.cn/api/v1/public/english/listening/items?page=1&pageSize=20&cefr=A1'
curl -fsS -o /dev/null -w 'resources-A1 %{http_code}\n' 'https://yulanlin.cn/api/v1/public/english/writing/resources?page=1&pageSize=20&cefr=A1'
curl -fsS -o /dev/null -w 'prompts-A1 %{http_code}\n' 'https://yulanlin.cn/api/v1/public/english/writing/prompts?page=1&pageSize=20&cefr=A1'
curl -fsS -o /dev/null -w 'bundles %{http_code}\n' 'https://yulanlin.cn/api/v1/public/english/bundles'
curl -fsS -o /dev/null -w 'pronunciation %{http_code}\n' 'https://yulanlin.cn/api/v1/public/english/listening/pronunciation'
```

六级批量检查：

```bash
for level in A1 A2 B1 B2 C1 C2; do
  curl -fsS -o /dev/null -w "$level reading %{http_code}\n" "https://yulanlin.cn/api/v1/public/english/reading/articles?page=1&pageSize=20&cefr=$level"
  curl -fsS -o /dev/null -w "$level listening %{http_code}\n" "https://yulanlin.cn/api/v1/public/english/listening/items?page=1&pageSize=20&cefr=$level"
  curl -fsS -o /dev/null -w "$level resources %{http_code}\n" "https://yulanlin.cn/api/v1/public/english/writing/resources?page=1&pageSize=20&cefr=$level"
  curl -fsS -o /dev/null -w "$level prompts %{http_code}\n" "https://yulanlin.cn/api/v1/public/english/writing/prompts?page=1&pageSize=20&cefr=$level"
done
```

HTTP 200 只证明接口可访问；仍需在浏览器中确认返回列表不是空数组，并完成练习判分与音频播放。

## 七、失败时如何定位

- 组合提示 `SUMMARY_REQUIRED`：编辑组合并填写本页摘要。
- 提示 `CEFR_REQUIRED`：选择当前组合的主要 CEFR。
- 提示 `MINIMUM_ITEMS_REQUIRED`：组合少于两项；本方案应加入三项。
- 提示 `MULTIPLE_MODULES_REQUIRED`：内容都来自同一模块；重新按本页加入阅读、听力、写作。
- 提示 `UNPUBLISHED_ITEMS_PRESENT`：组合内至少一项仍是草稿或已撤回；返回原模块完成发布。
- 已发布组合无法排序：这是正常锁定机制；先撤回组合，再调整并重新发布。
- 页面 404：记录实际请求地址和后台状态，确认使用的是系统生成编号，且内容为 `PUBLISHED`。
- 接口 401/403：公开接口不应要求后台令牌；检查 Nginx `/api/` 反向代理和后端权限配置，不要在命令中粘贴管理员令牌。
- 音频能播放但片段错位：根据成品音频重新测量毫秒边界；不要照搬文稿预计时长。
