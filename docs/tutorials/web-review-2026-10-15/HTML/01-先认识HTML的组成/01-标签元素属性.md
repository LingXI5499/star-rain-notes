## 一、学习目标

- 能从一行 HTML 中指出开始标签、内容、结束标签、属性名和属性值。
- 能根据内容用途选择标题、段落、链接和图片等常见标签。
- 能区分普通元素与空元素，正确添加属性和注释。
- 能修改一个简单页面，并说明文字、标签、属性分别改变了什么。

## 二、核心知识

### 2.1 从一个段落分清标签、元素与属性

HTML 的全称是 HyperText Markup Language，即超文本标记语言。写 HTML，是用浏览器认识的标记表达内容的身份与结构：哪一段是标题，哪一段是正文，哪里可以跳转，哪里需要显示图片。

先读这一行：

```html
<p class="note">这是一个段落。</p>
```

`p` 表示段落。这行代码可以拆成下面几部分：

| 部分 | 本例中的代码 | 含义 |
| --- | --- | --- |
| 开始标签 | `<p class="note">` | 段落从这里开始，也在这里声明属性 |
| 标签名 | `p` | 指明元素类型是段落 |
| 内容 | `这是一个段落。` | 段落中承载的文字 |
| 结束标签 | `</p>` | 这个段落到这里结束 |
| 属性名 | `class` | 属性的名称 |
| 属性值 | `note` | 给这个属性设置的值 |

**标签是标记，元素是整体。** `<p class="note">` 是开始标签，`</p>` 是结束标签，而从开始标签到结束标签的这一整段，是一个 `p` 元素。平时说“添加一个 p 标签”，通常是在说添加一个段落元素；分析代码结构时，要知道这两个词的区别。

`class="note"` 属于开始标签的一部分，用来补充元素信息，不属于段落正文。页面通常显示“这是一个段落。”，不会把 `class="note"` 当成正文打印出来。

再看没有属性的写法：

```html
<p>这是一个段落。</p>
```

它依然是完整的段落元素。是否需要某个属性，由元素用途和属性规则决定；不能把“元素一定要有属性”当成语法要求。

### 2.2 标签按内容的用途选择

HTML 已经定义了许多标签。初学时先认识下面几种，不必一次背完全部标签：

| 标签 | 表达的内容 | 简单写法 |
| --- | --- | --- |
| `h1`～`h6` | 不同层级的标题 | `<h1>我的学习笔记</h1>` |
| `p` | 一个段落 | `<p>今天开始学习 HTML。</p>` |
| `a` | 指向其他位置的链接 | `<a href="notes.html">阅读笔记</a>` |
| `img` | 图片 | `<img src="cover.png" alt="笔记本封面">` |
| `button` | 供用户触发操作的按钮 | `<button type="button">查看说明</button>` |
| `div` | 没有额外内容语义的通用容器 | `<div>一组相关内容</div>` |

选择标签时，先问“这是什么内容”。文章标题用标题元素，正文用段落，前往另一个页面用链接。不要因为 `h1` 默认看起来比较大，就把需要放大的所有文字都写成 `h1`；标题层级与具体字号是两个问题。

浏览器会为许多标签提供默认样式，所以没有编写 CSS，也能看到标题和段落的外观差异。这只是浏览器提供的默认显示方式。后面学习 CSS 时，还可以改变它们的字号、颜色和间距。

`button` 能提供原生按钮的基础交互，但写出“查看说明”四个字，不会自动生成查看说明的业务逻辑。标签提供的能力与页面需要实现的具体功能，要分别理解。

### 2.3 属性写在开始标签内

常见的属性写法是 `属性名="属性值"`。属性和标签名之间、多个属性之间，用空格分隔：

```html
<p class="note" title="这是补充说明">把鼠标停在这段文字上试试。</p>
```

这里有两个属性：`class` 的值是 `note`，`title` 的值是“这是补充说明”。本教程统一给属性值加引号，避免空格等字符造成歧义，也便于阅读。

属性不能随便写到结束标签上。段落的结束标签仍然是 `</p>`。

属性大致可以先分成两类：

| 类别 | 常见属性 | 用途 |
| --- | --- | --- |
| 全局属性 | `id`、`class`、`title`、`lang` | 为各种 HTML 元素提供标识、分类、补充信息或语言声明 |
| 与特定元素有关的属性 | `a` 的 `href`，`img` 的 `src`、`alt` | 配置链接目标、图片资源和替代文本等具体能力 |

“全局”表示属性具有广泛的适用范围，不表示写在任何元素上都会产生相同的可见效果。完整的全局属性与 `data-*` 留到本组后续章节讲解。

下面两行分别配置了链接和图片：

```html
<a href="notes.html">阅读笔记</a>
<img src="cover.png" alt="笔记本封面">
```

`href` 告诉链接跳到哪里；`src` 告诉图片从哪里加载；`alt` 提供图片的替代文本。先认清这些分工，后续章节再学习路径解析、图片选择和替代文本的具体写法。不能把给段落添加 `href` 当成创建链接的方法。

还有一个很容易误解的地方：**`class="note"` 只是把元素归入 `note` 这一类。** `note` 是自己取的类名，没有“自动变红”的内置含义。本章示例没有对应的样式规则，所以加上它之后，文字不会自动改变颜色。

`title` 也只是补充信息。桌面浏览器可能在鼠标停留时显示提示，但不能保证所有输入设备都能以同样方式查看，因此重要说明应该直接写在页面内容中。

### 2.4 普通元素、空元素与注释

前面的 `p` 有开始标签和结束标签，文字写在二者之间。`img` 则属于空元素，不能包含子内容，也没有结束标签：

```html
<!-- 普通段落元素：文字写在开始标签与结束标签之间。 -->
<p>记录今天学到的内容。</p>

<!-- img 是空元素，图片地址与替代文本通过属性配置。 -->
<img src="cover.png" alt="笔记本封面">
```

常见空元素还有 `input`、`br`、`hr`、`meta` 和 `link`。不要给它们添加 `</img>`、`</input>` 这样的结束标签。某些资料写作 `<img ... />`，在 HTML 中末尾的斜线不是必需的，也不表示所有普通元素都可以靠加一个斜线来结束。

`<!-- 说明文字 -->` 是 HTML 注释，用于给阅读源码的人解释意图，浏览器不会把它作为正文显示。但注释仍然存在于页面源码中，不能用它保存密码或其他秘密。

对于本章练习中的 `p`、`h1` 等元素，按示例写清开始与结束标签。HTML 确实允许部分元素在特定条件下省略某些标签，但不需要在第一章把这些省略规则混进来。

### 2.5 修改代码，核对页面结果

代码目录中的原例有一个标题和两个段落。下面保留它的学习内容，移除本章不需要的样式与脚本引用，得到可以单独打开的最小页面。

新建 `index.html`，用 UTF-8 编码保存以下内容，再用浏览器打开。先原样保留外层文档结构，本章只观察 `body` 中的三个元素；文档各部分会在第三章解释。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>标签、元素与属性</title>
</head>
<body>
  <h1>我的第一张网页</h1>
  <!-- note 只是类名；当前页面没有为它设置样式。 -->
  <p class="note" title="把鼠标停在这里">这是一个段落。</p>
  <p>这是另一个段落。</p>
</body>
</html>
```

打开后应看到一个大标题和两个段落。尖括号标记、属性和注释都不会作为正文打印出来；两个段落具有相同的默认外观。

然后分别进行以下修改。每完成一项都保存文件并刷新浏览器，观察完再恢复原样，避免多个修改互相干扰：

| 修改 | 应观察到的结果 | 对应的知识 |
| --- | --- | --- |
| 把第一段的文字改为“我知道元素是什么了” | 第一段文字改变，标题和第二段保持原样 | 两个标签之间是这个元素的内容 |
| 把第一段的 `class="note"` 改为 `class="warning"` | 本例外观不变 | 类名本身不规定颜色或字号 |
| 把第一段开始与结束标签中的 `p` 都改为 `h2` | 这段内容成为二级标题，默认外观通常也改变 | 标签名决定元素类型 |

第二项没有可见变化也是有效的实验结果。如果你的段落意外出现了颜色或其他样式，先确认打开的是这里独立保存的文件，并检查是否额外引入了 CSS。最后一项只用于观察元素类型的变化，实际写页面时仍应根据内容含义选择标题与段落。

## 三、问题

1. 在 `<p class="note">学习 HTML</p>` 中，哪些部分是开始标签、内容和结束标签？整个元素是哪一段？
2. `class="note"` 中的属性名与属性值分别是什么？如果不写这个属性，段落元素是否仍然成立？
3. 为什么 `class="warning"` 不会自动把文字变成红色？
4. 正文需要一个可以前往 `notes.html` 的链接，应该给 `p` 加 `href`，还是使用 `a`？为什么？
5. `<img src="cover.png" alt="笔记本封面">` 为什么没有结束标签？`src` 和 `alt` 分别配置什么？
6. HTML 注释会作为正文显示吗？不显示是否意味着别人无法从源码中看到？
7. 第一段只是普通说明文字，能否仅为了让它变大，就把它改成 `h1`？应该先根据什么选择标签？

## 四、练习题

### 4.1 拆解与修正

阅读下面的代码：

```html
<h1>学习记录</h1>
<p class="daily" title="今天的学习内容">我认识了三个术语。</p>
<img src="cover.png" alt="学习笔记封面"></img>
```

完成两项任务：

1. 写出第二行的标签名、两个属性名、各自的属性值、元素内容和结束标签。
2. 修正第三行的空元素写法，并说明 `src` 与 `alt` 的职责。

**验收标准：**能指出 `p`、`class`、`daily`、`title` 及其对应值，不把属性当成正文；修正后保留 `img` 的两个属性并移除 `</img>`。这是一道代码阅读题，不要求实际提供 `cover.png` 文件。

### 4.2 编写学习记录页

复制本章完整页面的外层结构，仅替换 `body` 中的内容，完成以下页面：

- 一个主标题，内容为“我的 HTML 学习记录”。
- 两个段落，内容依次为“今天我认识了标签、元素和属性。”与“下一步学习元素之间的关系。”。
- 第一段添加 `class="learning-note"` 和 `title="第一天的记录"`。
- 在第一段前添加一条注释，说明它记录当天所学。

**验收标准：**浏览器显示一个标题和两个段落，顺序与文字正确；源码中能够找到要求的两个属性和注释；页面没有引入 CSS，第一段不会仅因类名而自动变色，注释和属性也没有被打印成正文。
