# Markdown 图片插入与媒体入库

编辑器图片按“插入 → 媒体库登记 → 公开地址 → 保存正文建立引用”的链路处理，不需要先到媒体管理页公开图片。

## 插入入口

- 文件上传、截图粘贴、图片拖拽：上传时使用 `PUBLIC`，成功后插入服务端返回的媒体地址。
- 媒体库选图：在插入动作中准备图片；受保护图片由上传者或有访问管理权限的账户公开，已有公开图片直接复用。
- 复制网页图文、粘贴 Markdown、导入 Markdown 文件、修改图片地址及直接输入图片语法：识别正文中的图片，保存到媒体库并改用站内媒体地址，保留周围文字、替代文本和尺寸说明。同一批内容中的重复图片地址只导入一次，代码示例中的图片语法不处理。
- 外部图片优先使用浏览器已有的网络连接读取，使用不携带账户凭据的请求；来源不允许跨域读取时，调用服务端导入。服务端仅下载公开 HTTP(S) 图片，逐次检查重定向、连接地址、读取时间及体积，随后复用现有上传签名校验与事务补偿。

来源不可访问、格式不支持或图片过大时显示错误，不伪造入库成功。对于需要外站登录或拒绝下载的图片，可保存原图后上传。浏览器无法直接读取的本机文件路径应通过文件选择或拖拽提交。

## 接口与授权

- `POST /api/admin/media/assets`：图片未指定访问级别时默认公开；显式提交的访问级别继续生效，其他文件默认策略保持原有规则。
- `POST /api/admin/media/editor-images/{id}/prepare`：准备一张插入正文的图片，返回媒体对象及其公开地址。
- `POST /api/admin/media/editor-images/import`：接收 `{ "url": "https://…" }`，下载并注册公开图片。

两个编辑器接口均要求登录、`media:upload` 权限及有效 CSRF 令牌。准备图片只接受有效图片；不能通过该接口公开其他账户的受保护素材，除非调用账户已有 `media:access-manage` 权限。不会批量公开媒体库中的历史文件。外部下载不发送站内 Session 或外站认证信息。

服务端下载保留 TLS 证书校验；限制为标准 HTTP(S) 端口、最多三次跳转及不超过现有图片大小限制（最高 20 MB）。在实际 DNS 连接处检查地址，拒绝回环、内网、链路本地及保留地址，避免图片导入变为内网请求入口。

博客、教程、作品与英语编辑页共用编辑器。保存和发布仍沿用各模块的身份、权限、内容版本及媒体引用规则。切换文档、只读状态变化或组件卸载后，旧异步结果不能插入新文档；正文在导入期间变化时，不覆盖新正文。

## 验证

在独立测试数据库中验证上传、粘贴、拖拽、网页图片、Markdown 文件导入、直接输入图片、博客保存、引用数量和匿名读取。所有验证资料与测试账户留在本地隔离环境，不改动真实账户密码或用户正文。远程下载的网络可达性取决于运行环境；本地已验证通过浏览器读取公开图片并完成入库。
