# V2.2 手动部署与新增配置

交付文件只有 `app.jar` 和 `dist.zip`，zip 内包含 `dist/index.html`、`dist/assets/` 等完整前端。说明文档在仓库中单独提供。源码整改不代表服务器已经升级。

## 需要追加的 YAML

如果启用了 SMTP，在现有外部 application.yml 的**顶层**增加以下键，不要再新建重复的 `spring:` 或 `star-rain:`。若已有同名键则更新原键。

```yaml
STAR_RAIN_MAIL_OUTBOX_KEY: '填入服务器生成的固定32字节Base64密钥'
STAR_RAIN_MANAGEMENT_PORT: 18089
```

密钥生成命令：`openssl rand -base64 32`。把结果保存在服务器 YAML 或进程环境，禁止粘贴到公共源码。SMTP 未启用时无需设置邮件密钥；SMTP 启用但密钥缺失/错误时发信接口返回配置不可用，不能绕过加密。管理端口默认就是 18089，只有冲突时才需另选空闲端口；监听地址在包内固定为 127.0.0.1。

其他现有数据库、SMTP、媒体绝对路径、HTTPS Cookie、代理信任和公开域名配置沿用已核验的配置。`STAR_RAIN_FRONTEND_INDEX_PATH` 必须指向此次 dist/index.html。不要为了本次升级把主域名或媒体根目录换掉。

## 上线顺序

1. 冻结后台保存/上传/审核，等待在途写入结束。保存旧 JAR、整份 dist 和配置，完成一致性数据库+媒体备份；已启用发信队列后也备份密钥。
2. 在副本演练 Flyway 2.041–2.046；核对摘要回填耗时与磁盘余量。新迁移新增列/表，不能通过修改旧脚本或删除历史来回滚。
3. 停旧 Java，上传新 app.jar 与完整 dist。更新时保留以前的哈希 assets，避免未刷新的浏览器请求旧 chunk 404；保留百度/Google 验证 HTML 文件及 Bing 验证文件，不用空文件或 SPA 首页代替它们。
4. 合并上述新增顶层 YAML。可在运维环境安装 PyYAML 后运行 `python tools/validate_deployment_config.py /path/to/application.yml`；脚本只检查语法/重复键，不输出配置值。仍需人工核对凭据与目标路径。检查 `nginx -t`。
5. 用原有 Java 21 服务启动参数启动新包，等待 `curl --fail http://127.0.0.1:18089/actuator/health/readiness` 返回 200 且 UP，再开放流量。不能只以 Java 进程存在作为就绪。
6. 访问 `/api/public/site/build-info` 与 `/build-info.json`，前后端提交必须一致；检查 JAR SHA-256 与本地交付记录一致。
7. 旧页面需要刷新再编辑。新博客/作品写接口和学习进度需要版本条件，旧客户端可能得到 428；不要关闭版本检查来兼容旧页面。409 应保留当前输入、对比服务器版本后再保存。
8. 完成登录、CSRF、保存/发布/撤回、草稿媒体、图片条件请求、学习进度、SMTP、Sitemap、手机页面、筛选位置与专题/标签删除回归。

## Nginx 需要核对的规则

以下是**要合并的片段**，并非完整 server 配置。示例应用端口为 18088，按现有实际端口核对；已经有同路由 location 时修改原规则，不叠加重复 location。既有 HTTPS/根目录/上传限制保留。

```nginx
location ^~ /api/ {
    proxy_pass http://127.0.0.1:18088;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_read_timeout 120s;
}
location ^~ /actuator/ { return 404; }
location ^~ /assets/ {
    try_files $uri =404;
    expires 1y;
    add_header Cache-Control "public, immutable";
    add_header Referrer-Policy no-referrer always;
}
location ^~ /brand/ { try_files $uri =404; }
location ^~ /legal/ { try_files $uri =404; }
location = /build-info.json {
    try_files $uri =404;
    add_header Cache-Control no-cache;
    add_header Referrer-Policy no-referrer always;
}
location = /index.html {
    add_header Cache-Control no-cache;
    add_header Referrer-Policy no-referrer always;
}
# Redirect old bookmarks/mail links before serving HTML. $args keeps encoded tokens/return URLs.
# Browsers retain the original fragment when Location supplies no new fragment.
location ~ ^/useradmin(?:/(?<legacy_path>.*))?$ {
    return 308 /$legacy_path$is_args$args;
}
# Verification files and missing static files must never fall back to the SPA.
location ~ ^/(?:baidu_verify_[A-Za-z0-9_-]+|google[A-Za-z0-9_-]+)\.html$ { try_files $uri =404; }
location = /BingSiteAuth.xml { try_files $uri =404; }
location ~* \.(?:js|mjs|css|map|png|jpg|jpeg|gif|svg|webp|ico|woff2?|ttf|wasm|html)$ {
    try_files $uri =404;
}
# Account/management routes precede the backend public SEO gateway, including overlapping paths.
location ~ ^/(?:(?:login|register|forgot-password|reset-password)/?$|invitation/accept/?$|(?:center|learning|dashboard|accounts|invitations|audits|permissions|site|analytics|media|reviews|profile)(?:/|$)|blog/(?:manage/?$|taxonomy/?$|topics/?$|editor/[^/]+/?$)|tutorials/(?:(?:manage|cards|questions|exercises)/?$|editor/[^/]+/?$|[^/]+/(?:preview|curriculum)/?$|[^/]+/chapters/[^/]+(?:/(?:cards|questions|exercises))?/?$)|portfolio/(?:manage/?$|(?:editor|preview)/[^/]+/?$)|messages/manage/?$|english/(?:manage(?:/|$)|writing/articles/(?:new/?$|[^/]+/(?:edit|revisions)/?$))) {
    # Serving index as an existing file avoids an internal redirect losing X-Robots-Tag.
    try_files /index.html =404;
    add_header Cache-Control no-cache;
    add_header X-Robots-Tag "noindex, nofollow" always;
    add_header Referrer-Policy no-referrer always;
}
location ~ ^/portfolio/[^/]+/live/?$ {
    try_files /index.html =404;
    add_header Cache-Control no-cache;
    add_header X-Robots-Tag "noindex, nofollow" always;
    add_header Referrer-Policy no-referrer always;
}
# Public English/legal/search pages remain client-rendered. Public English must stay indexable.
location ~ ^/(?:english(?:/|$)|terms/?$|privacy/?$|search/?$) {
    try_files /index.html =404;
    add_header Cache-Control no-cache;
    add_header Referrer-Policy no-referrer always;
}
# Public HTML, robots and sitemap use backend SEO snapshots and retain real 404 responses.
location / {
    proxy_pass http://127.0.0.1:18088;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Real-IP $remote_addr;
}
```

正则 location 的先后顺序很重要：验证文件应在公开博客等正则之前，哈希 assets 的 ^~ 优先。若现有广泛 `location ~* \\.(js|css|...)` 缓存规则覆盖媒体 API，应去掉这种覆盖并检查真实响应。后端反代信任采用已有 V2.1 部署规则，不转发管理端口；API Cache-Control 由应用决定。

已启用 IndexNow 且 key 有效时，验证文本由 `/api/public/seo/indexnow-key.txt` 返回，通知中的 keyLocation 指向此接口；不需要另外把 key 打包到 dist。Google/百度的所有权验证和 IndexNow 不是同一个验证文件。

## 指标与恢复

健康探针匿名只返回状态。指标在独立回环端口要求 HTTP Basic 站点账号认证且拥有 `site:dashboard-read`；服务器本机使用安全凭据方式读取 `/actuator/metrics`，不要把该端口代理到公网。可观察 HTTP 请求延迟、Hikari 连接池、`star.rain.projection.pending`、`star.rain.mail.pending`。指标本身不会主动发告警；监控告警渠道需在服务器配置。

本地已演练恢复 107 张表与 1 个测试媒体文件，不能当作生产备份已经验证。生产恢复必须在新库与新媒体目录启动禁用 SMTP、IndexNow、管理员初始化、孤儿清理的应用，核对公开/草稿状态、引用、SHA、权限与 schema 后再切换。

回滚：先停写，再切回旧 JAR/dist。新增表列留存不等于旧程序的全部工作流安全兼容，新版本写入后尤其不要让两个版本同时运行。若需要回到升级前一致状态，使用升级前同一恢复点数据库+媒体备份，接受该恢复点以后的写入损失。不要从 Flyway 历史删除 2.041–2.046，也不要在生产直接 DROP 新列/表。
