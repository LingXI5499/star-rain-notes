# 仪表盘与英语管理完善说明

## 仪表盘及访问统计

引入 ECharts 6.1.0 与 vue-echarts 8.3.2。共享图表按需加载折线、柱状、环形图与 SVG 渲染器，图表依赖独立于首屏入口包。图表响应容器大小、浅深色主题和减少动画偏好，提供明细表格。

- 仪表盘保留原有内容卡片、待处理项和最近内容，增加近 7 天或 30 天访问双折线图及内容数量条形图。访问图表及详情入口遵守现有访问统计权限。
- 访问统计展示累计及今日数据、范围趋势、热门内容 TOP 10 和访问来源。支持近 7 天、近 30 天及自定义日期。累计与今日概览不受范围筛选影响，页面明确说明口径。
- 页面访问和内容访问分别展示，不相加作为访客总量，不称为 UV。日期继续使用后端 UTC 口径，缺少事件的日期补零。表单校验与后端的最大 366 天日期跨度一致。
- 各面板独立请求、独立报错和重试；旧请求不能覆盖新查询。空数据不伪造图形，失败不显示为零访问。

## 语法课程

语法课程保留自身内容模型和现有授权，管理交互与普通教程目录一致：左侧章节、右侧直属课时；提供新建、编辑、删除、同级拖动和上移下移。课时保留独立发布与撤回，已公开的课时可预览。搜索期间暂停课时排序，不从筛选结果提交残缺目录。

删除非空章节时，确认框显示其课时数量并明确删除范围。后端在事务中锁定课程结构，验证章节存在，先删除直属课时，再删除章节，并通知搜索索引刷新。排序要求提交完整的当前同级 ID 集合，拒绝重复、跨章节或过期目录。此次没有执行实际课程删除。

发布、撤回及删除继续使用英语模块既有权限与状态机制，没有迁移到普通教程的审核模型，也未为语法新增一套审核流程。

## 词汇与记忆

新增单词和主题不再进入旧词层管理页面。旧来源管理地址转向新词汇管理页，并打开新增单词表单。分类表单仅保留父分类和中英文名称；编号与稳定标识由后端生成，编辑名称保留既有链接与引用，停用保留历史资料。

新增词条在同一事务里创建并关联当前二级主题，释义及其它补充资料可为空。前后台共用精简词卡，记忆学习入口和待选操作恢复到当前词库。历史来源主题的记忆链接另保留兼容，原计划、三方向训练、评分与记忆算法未重写。

词典与音频自动补全的数据源、交互及接入边界见 [词汇资料补全方案](vocabulary-dictionary-enrichment-plan.md)。第三方自动补全尚未接入。

后续已补齐当前词库的筛选全选、计划确认和学习记录衔接，完整流程及独立数据库验证见 [单词记忆流程](vocabulary-memory-flow.md)。以下验证数据保留本轮原始范围，后续记忆功能验证以该说明为准。
