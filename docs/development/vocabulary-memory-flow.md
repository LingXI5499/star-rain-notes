# 当前词库的记忆学习流程

本次以现有两级分类、精简词卡和配色为界面基础，参考已保留的记忆业务设计，补齐新词库与学习计划之间的交互。未恢复旧词层管理界面，也未改写已有记忆算法。

## 已接通的流程

1. 在一级分类、二级主题和搜索结果中手选词汇，支持跨页和跨主题保留待选。登录后可全选全部匹配结果，排除个别词汇，或反选当前页。
2. 在折叠区域按已学、未学、熟练度、当前计划范围、评价方向和最近评分筛选。全选由服务端筛选，不把整个词库下载到浏览器；改变筛选范围会清除原全选并提示，手选保持。
3. 点击“查看待选并设置计划”，核对词数、已学词数和分组，移除不需要的词，设置每组 5–100 词。勾选确认项后才能创建；替换当前计划前显示影响范围。浏览和预览不产生评分。
4. 每组先自由双语预览，正式训练依次为英译中、中译英、听音辨词。刷新后可从服务端的默认待学位置继续，各方向分别记录完成状态。
5. 揭晓答案后评价掌握、模糊或忘记，写入现有方向记忆和评分历史。听音训练在实际播放成功前不能揭晓或评分，播放前隐藏单词、释义和音标。
6. 到期方向进入“今日背单词”，按现有批次规则复习；词卡显示累计记忆次数和熟练度。替换或取消计划保留永久记忆、历史评分和到期复习。

只填写单词的最小词条仍可保存和浏览；没有有效释义的词条暂不参与记忆选词，补充资料后即可加入。游客手选保留在当前浏览器标签页，创建正式计划先登录。浏览器草稿不是永久学习记录，后者仍归属于账号。

## 与历史逻辑的衔接

- 保留一个账号一个当前计划、计划版本和选词内容校验；过期确认仍由后端返回冲突。
- 保留默认每组 20 词、三方向独立评分、方向熟练度和间隔复习、跨日毕业条件、重复评分防护、删除词条快照与跳过规则。
- 当前分类代码、主题代码和分类状态直接传入既有学习筛选接口，词库展示与全选使用同一筛选条件。旧来源主题仍可访问当前精简词卡，草稿不会退回旧界面。
- 本次新增后端筛选字段和参数绑定 SQL，没有新增数据库迁移，没有修改账号、Session、CSRF 或权限规则。
