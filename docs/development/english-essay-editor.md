# 随笔与世界文章编辑方案

## 范围与流程

随笔管理提供新增、读取、修改、软删除、关键词与状态条件分页。新建页先在本地编辑，首次保存才建立草稿，避免进入页面即新增空文章。所有文章按本人原创处理，编辑界面只保留标题、英文原文和中文翻译；世界文章保留必要分类，来源及版权材料不再要求填写。世界文章在用户明确保存时按原创规范化来源元数据，不批量改写存量记录。

随笔状态：草稿 DRAFT → 提交审核 PENDING → 通过后 COMPLETED/PUBLIC；驳回后 REJECTED/PRIVATE，可修改后重新提交；申请人取消送审后回到 DRAFT。已发布文章先撤回至草稿再修改，不允许自动保存修改公开内容。审核接入现有审核中心，冻结历史版本；送审期间禁止修改、恢复和删除。通过、驳回及取消均使用现有审核权限及审计，不新增身份旁路。兼容旧完成状态，只有发布权限者可以发布已完成文章。

正文保存和状态转换使用 rowVersion，冲突时保留当前文本；删除由服务端加锁、核对归属及状态后软删除。删除公开文章之前必须撤回。不删除历史版本。审核回调按冻结版本确认目标仍待审，重复回调不重复发布。

## 界面

管理页：搜索标题/关键词，状态筛选（草稿、待审核、已驳回、已完成、已发布），每页 10/20/50 条。切换条件回第一页，筛选及页码保存在 URL，删除末页最后一条自动回退。

编辑页：顶部标题与状态、保存和提交审核；正文区域左右两列为中文和英文，各自使用现有 Markdown 编辑器。不再提供摘要字段，随笔不要求分类。默认原创，不展示来源、作者、版权核查表单。宽屏两栏，窄屏同一对应项上下展示。

阅读预览与公开详情使用同一对应组件。普通段落内按句序拆分为对应项，左右同序对应并同高排列；缺失译文明确显示待补充，不自动推断或生成译文。保留原有 Markdown、代码、表格和公式块。旧内容按现有段落对应，无需改写数据库正文。

保存失败时保留正文、展示重试；离开未保存页先尝试保存，失败时提供继续编辑或明确放弃的选择，避免点击无反馈。正文 null 在共享编辑器入口及业务表单都归一为字符串。

## 验证

前端回归：空正文、创建失败、保存与版本冲突、离开导航、分页筛选、末页删除、对应段落、窄屏。后端回归：对象权限、CAS、送审锁定、通过/驳回/取消、禁止直接修改或删除公开文章。数据库集成测试仅使用独立测试库。构建和自动化测试分别报告数量；本地结果不代表生产部署。
