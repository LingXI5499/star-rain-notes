# 英语文章内容简化

英语随笔、世界文章和个人写作的主要内容统一为标题、英文原文、中文翻译。移除摘要输入及其在英语文章列表、详情、审核预览中的展示，不再显示“暂无摘要”等占位提示。现有分类、保存、版本冲突、审核及发布规则继续使用原有实现。历史摘要字段保留兼容，不执行数据库清理或结构变更。

双语预览和前台文章使用同一逐句对照组件，延续中文在左、英文在右的当前布局；手机按一组一组上下对应。普通段落内的多句话也按句序配对，不要求每句话都手工空一行。两种语言需按相同句序编写；句数不同会显示待补充位置，不自动推断翻译关系。标题、列表、代码、表格、公式和媒体保持完整块。

拆句在完整 Markdown 文档经过既有渲染和安全处理后执行，保留链接、行内格式、标题目录和沙箱容器。修复了原对照逻辑将沙箱外壳视为正文块、从而整篇并列的问题。英文常见称谓缩写、姓名首字母、小数和引号后的叙述句作边界处理。
