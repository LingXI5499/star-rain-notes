# 词汇资料补全方案

## 已实现的基础

词汇管理统一使用当前一级分类与二级主题。新增仅需分类、主题和单词；释义、音标、词性、主题用法、例句及词形可后续补充。系统内部自动维护兼容旧学习记录所需的存储关联，管理者不再填写旧词层信息。现有词条编辑保留原主键、学习身份及未编辑的补充字段。

前后台浏览共用精简词卡，展示单词、英美音标、发音按钮、中文释义与本主题用法。词卡不再展示迁移状态、旧主题编号、来源记录序号或长例句。现有例句仍保留在数据中。

发音复用现有播放器：词条已关联音频 → 现有后端发音接口 → 浏览器语音合成。页面切换时停止当前播放。此处接通的是已有能力，不代表第三方发音来源已经完成可用性或存储授权验证。

记忆选择直接在当前两级分类词库中进行，跨分类、筛选与分页保留词 ID。用户先预览、确认计划，再进入既有英译中、中译英及听音训练。选词不会立即替换现有计划；旧主题选择草稿、旧计划和历史记忆记录保留。新建而尚未填写释义的词可以保存，补齐释义后再进入记忆待选。

## 建议的数据源

| 数据 | 建议来源 | 适用边界 |
| --- | --- | --- |
| 音标、词性、英英释义、英文例句、部分音频地址 | Free Dictionary API，作为开发与试用候选 | 不能据此保证中文释义或所有词都有英美音频；写入前应核对每条资料与音频的来源及许可 |
| 中文词义、双语例句、完整词典资料 | 选择允许站内保存和展示的授权词典数据，或签约的词典接口 | 需要确认词库保存、再展示和音频使用范围，不能把临时查询接口默认当作可下载词库 |
| 自写例句及主题用法 | 编辑维护；后续可增加独立的内容生成接口 | 应标为候选内容，由编辑确认；不冒充原词典的例句 |
| 发音兜底 | 浏览器语音合成或明确配置的语音服务 | 合成发音与真人录音分别记录，不把合成音标记成真人音频 |

[Free Dictionary API 官方说明](https://dictionaryapi.dev/)列出了音标、音频、词性、释义及例句的响应示例，接口本身不保证中文翻译。

[有道词典 API 官方说明](https://ai.youdao.com/DOCSIRMA/html/dictionary/api/ydcd/index.html)列出了中英词典资料，但公开文档同时限制结果缓存、再利用和转卖。因此在获得适用于本项目的书面授权前，不将它作为“自动采集并保存本地词库”的默认方案。

[Cambridge 数据授权说明](https://dictionary.cambridge.org/license)提供词典及音频授权申请渠道，可作为完整授权数据的候选；目前未申请或采购。

## 计划中的补全交互

1. 编辑输入单词后，点击“查询词典”，后端只提交单词和所选语言，不传账号或学习记录。
2. 适配器返回候选释义、音标、例句及音频来源。记录提供方、来源链接、查询时间、许可及可保存字段。
3. 页面逐项预览；默认仅勾选当前为空的字段。已有人工内容不自动覆盖。
4. 音频由配置的允许域名提供；只有许可允许时才下载到媒体存储。校验文件类型、大小、超时及重定向，不接受任意网址抓取。
5. 用户确认后，通过现有词条保存接口及版本号提交。查询失败、未收录、配额不足时保留表单，仍可只保存单词。

如增加后台异步补全，任务应记录待处理、查询中、待确认、完成和失败状态，支持幂等与有限重试。密钥仅保存在后端配置中。缓存期限和可保存内容由具体提供方的许可决定。

## 本次边界

以上第三方词典补全属于方案，尚未新增查询适配器、自动采集任务或批量生成操作，也未配置词典密钥、下载词典或购买服务。现有发音代理的配置保持不变；真实上游音频及数据库集成验收为 NOT_VERIFIED。
