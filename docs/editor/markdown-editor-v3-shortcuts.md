# Markdown 编辑器 V3 快捷键

默认按键只作用于拥有焦点的当前编辑器；表单、另一编辑器以及中文输入法组合输入期间不会响应标题命令。

| 按键 | 功能 |
| --- | --- |
| Alt+0 | 普通正文 |
| Alt+1–Alt+6 | H1–H6，替换已有级别，保留行内格式 |
| Ctrl+B / Ctrl+I | Vditor 原生加粗 / 斜体 |
| Ctrl+Z / Ctrl+Y | Vditor 原生撤销 / 重做 |
| 行首 / | 打开段落命令菜单，可输入中文名称或 h2 等关键词 |
| ↑ / ↓ / Enter | 移动命令候选 / 确认；输入法候选期间不会抢占 |
| Escape | 关闭命令菜单、浮动工具栏或帮助；未执行的查询保留在原文 |
| 表格中的 Tab / Shift+Tab | 保留 Vditor 原生单元格导航，界面外仍使用浏览器焦点导航 |

「快捷键 ?」中可修改七个标题快捷键。允许 Alt+数字/字母或 Ctrl+Shift+字母；重复键、配置结构错误和已知浏览器保留组合会被拒绝。设置只按账号保存在当前浏览器，未登录时只在当前实例生效；支持恢复默认。Vditor 原生标题提示随配置更新。

Windows 的 Alt、AltGr、浏览器菜单、系统快捷键与输入法可能发生冲突。拒绝 Ctrl+Alt、AltGraph、重复 keydown、isComposing 和 keyCode 229；不能因此保证所有物理键盘和输入法都不拦截按键。没有响应时可使用工具栏 H1–H6 / 正文按钮。macOS 的 Option/Command 组合需要人工验收，本轮未宣称支持系统级组合键重映射。

普通单行段落可以切换标题；源码模式可以对多个完整普通块操作。代码围栏、数学块、表格、代码组不转换为标题；多行段落、Setext 标题、跨复杂块选区会明确拒绝有损转换。IR/WYSIWYG 的跨段标题操作提示使用源码模式。

普通文档默认即时渲染。超过 100,000 字符的正文使用 Vditor 原生源码视图，阅读效果由「阅读预览」查看，避免同时保留多个大型编辑树。固定版本对部分表格行内代码的模式转换可能有损，因此模式切换有内容校验和回退提示。

Windows Edge 的自动化事件、撤销与双实例测试已有证据；Windows Chrome/Edge 的人工物理键盘、真实中文输入法、触摸选择尚待验收。
