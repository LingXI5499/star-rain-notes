# 编辑器大纲与正文画幅

大纲与正文使用编辑器内部的两列布局，顶部和底部对齐，各自滚动。大纲宽度不再固定为 224px，高度不再单独限制为 640px。容器宽度不足 640px 时，大纲改为正文上方的紧凑区域，避免挤压正文或覆盖页面导航。

- 拖动大纲与正文间的分隔线调整宽度，范围为 160px 至 480px，并限制为当前编辑器宽度的 45%。双击恢复 224px。
- 分隔线支持键盘左右方向键，每次调整 16px；Home 调至最小，End 调至当前可用最大宽度。
- 点击大纲右上角关闭按钮隐藏；菜单栏“大纲”按钮或“视图”菜单可恢复。隐藏后正文自动占用可用空间。
- 编辑器底部“正文画幅”滑块可设置 480px 至 1600px 的目标宽度，“铺满”恢复自适应。可用空间不足时自动收窄，不产生额外页面横向滚动。
- 大纲宽度、正文画幅及显示偏好按账号、模块、字段保存，仅保存布局数值。操作不会重建编辑器实例，不修改正文或保存接口。
