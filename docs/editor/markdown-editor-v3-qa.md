## 导出补充

Word 输出是真实 `.docx` OOXML ZIP；测试解压 `word/document.xml` 验证标题、表格、两个代码组面板、公式源码和媒体链接，浏览器下载通过。公式保留 TeX，不冒充 Word 原生公式；图片保留替代文本与链接，不自动公开或抓取受保护图片。实际 Word/WPS 打开和排版仍待人工。

PDF 采用隔离打印页面，复用净化后的公开阅读 HTML 与 MathJax，输出全部代码组面板、表格和可加载图片。浏览器打印对话框中选择「另存为 PDF」。打印取消不等于生成文件；真实打印对话框/分页和图片加载人工待验。打印隔离、安全 HTML、过期任务和 iframe 清理单元已覆盖。

PDF / Word 没有导入入口，文件类型校验也拒绝这些格式。

## 性能与限制

长文质量检查在独立 worker 中执行，面板关闭或身份变更会终止旧任务；小文检查防抖 650 ms。恢复点写入防抖 1.8 秒，页面隐藏时尝试写入，记录 SHA-256、基线、时间和结构版本；只在正文变更后写入。

单 worker 测量（`.local/editor-v3-perf-optimized.log`）为单次键入到下一动画帧的本机自动化观察，包含浏览器调度，并非生产 Web Vitals 或持续输入的 p95：

| 目标字符数 | 输入到下一帧 | JS 堆内存 |
| --- | ---: | ---: |
| 5,000 | 45.6 ms | 74,719,789 B |
| 50,000 | 138.1 ms | 183,028,537 B |
| 100,000 | 1,425.2 ms | 81,146,708 B |
| 200,000 | 1,913.2 ms | 92,698,740 B |

200k 的原策略测得 10,989.6 ms / 1,078,884,998 B；关闭原生同步预览、较大文档从 SV 启动、避免每次光标变更复制全文后显著下降。100k/200k 仍有明显延迟，不能宣称大文档达到普通文档流畅度；当前瓶颈包括固定 Vditor 的全文源码渲染与撤销差分。50k 单 worker 达到建议的 150 ms 目标；最终两 worker 并行验收测得 199.7 ms，所以不能宣称稳定达到该目标。最终并行验收的 5k/100k/200k 分别为 43.4/1,458.8/1,905 ms。自动化使用宽松的 5 秒防失控上限，不能把这一上限当作用户体验目标。

完整人工验收尚未完成，尤其是真实中文 IME、移动触摸、真实 Word/PDF 排版、持续长文输入与内存。不得将本报告解释为 28 项全部人工验收通过。
