1. 数组 Array

1.1 核心概念

数组是固定长度、存储同一种类型数据、通过下标访问元素的容器。

int[] arr = {10, 20, 30};

核心特征：

  • 下标从 0 开始。
  • 最后一个下标是 arr.length - 1。
  • 创建后长度不可改变。
  • 基本数据类型数组存储值。
  • 引用数据类型数组存储对象引用。
  • 根据下标访问元素：O(1)。
  • 中间插入、删除通常需要移动元素：O(n)。

2. 数组创建

2.1 静态初始化

int[] arr = new int[]{1, 2, 3, 4};

简化写法：

int[] arr = {1, 2, 3, 4};

2.2 动态初始化

int[] arr = new int[5];

默认值：

3. 数组基本操作

3.1 获取元素

int value = arr[0];

arr[0] = 100;

int length = arr.length;

length 是数组的字段，不是方法。

3.4 普通遍历

    System.out.println(arr[i]);

3.5 增强 for

适合：只读取元素。

4. 数组常用算法

求和

int sum = 0;

for (int value : arr) {
    sum += value;
}

最大值

int max = arr[0];

for (int value : arr) {
    if (value > max) {
        max = value;
    }
}

最小值

int min = arr[0];

for (int value : arr) {
    if (value < min) {
        min = value;
    }
}

平均值

double average = (double) sum / arr.length;

方差

double variance = 0;

for (int value : arr) {
    variance += (value - average) * (value - average);
}

variance /= arr.length;

数组反转

for (int left = 0, right = arr.length - 1;
     left < right;
     left++, right--) {

    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;
}

元素交换

int temp = arr[i];
arr[i] = arr[j];
arr[j] = temp;

顺序查找

int index = -1;

for (int i = 0; i < arr.length; i++) {
    if (arr[i] == target) {
        index = i;
        break;
    }
}

时间复杂度：

O(n)

中位数

先排序。

奇数个元素：

median = arr[arr.length / 2];

偶数个元素：

median = (arr[arr.length / 2 - 1] + arr[arr.length / 2]) / 2.0;

众数

核心思想：

统计每个元素出现次数
→ 找出现次数最多的元素

后续学习 HashMap 后推荐使用：

7. 数组综合案例

import java.util.Arrays;

public class ArrayDemo {

    public static void main(String[] args) {

        int[] nums = {7, 2, 9, 4, 2, 6};

        int sum = 0;
        int max = nums[0];
        int min = nums[0];

        for (int num : nums) {
            sum += num;

            if (num > max) {
                max = num;
            }

            if (num < min) {
                min = num;
            }
        }

        double average = (double) sum / nums.length;

        double variance = 0;

        for (int num : nums) {
            variance += (num - average) * (num - average);
        }

        variance /= nums.length;

        int[] sorted = Arrays.copyOf(nums, nums.length);

        Arrays.sort(sorted);

        double median;

        if (sorted.length % 2 == 1) {
            median = sorted[sorted.length / 2];
        } else {
            median =
                    (sorted[sorted.length / 2 - 1]
                    + sorted[sorted.length / 2]) / 2.0;
        }

        System.out.println("原数组：" + Arrays.toString(nums));
        System.out.println("排序后：" + Arrays.toString(sorted));
        System.out.println("和：" + sum);
        System.out.println("最大值：" + max);
        System.out.println("最小值：" + min);
        System.out.println("平均值：" + average);
        System.out.println("中位数：" + median);
        System.out.println("方差：" + variance);
    }
}

11. String 综合案例

public class StringDemo {

    public static void main(String[] args) {

        String text = "  Java,MySQL,Spring Boot  ";

        text = text.strip();

        System.out.println(text);
        System.out.println(text.length());

        System.out.println(text.contains("Java"));
        System.out.println(text.startsWith("Java"));
        System.out.println(text.endsWith("Boot"));

        int index = text.indexOf("MySQL");

        System.out.println(index);

        String[] technologies = text.split(",");

        for (String technology : technologies) {
            System.out.println(technology);
        }

        String result = text
                .replace("Java", "JavaSE")
                .toUpperCase();

        System.out.println(result);
    }
}

  1. equals() 不只比较数值，还会考虑 scale。
