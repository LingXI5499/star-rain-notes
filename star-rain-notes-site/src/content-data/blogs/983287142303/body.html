在学习 Java 时，我们经常会看到一句话：

Java 有 8 种基本数据类型。

这句话本身没有错，但它只回答了“Java 有多少种基本数据类型”，并没有回答“Java 一共有多少种数据类型”。

如果把 Java 的完整类型系统展开，我们会发现：

  • byte、int、double 等只是基本类型；
  • String、Student、ArrayList 属于类类型；
  • List、Runnable 属于接口类型；
  • int[]、String[] 属于数组类型；
  • 泛型中的 T 属于类型变量；
  • List<String> 属于参数化类型；
  • ? extends Number、Number & Comparable<?> 等则属于 Java 泛型和类型推导体系中的高级类型结构。

因此，Java 并不存在一个“所有具体类型加起来一共 N 种”的固定答案。

原因很简单：程序员可以不断定义新的类、接口、数组组合和泛型类型。

这篇文章将从 Java 语言规范的视角，把 Java 类型体系完整梳理一遍。

一、先给出结论：Java 类型到底有多少种？

如果问题是：

Java 有多少种基本数据类型？

答案是：

8 种。

byte
short
int
long
float
double
char
boolean

如果问题是：

Java 的类型主要分为哪两大类？

最标准的回答是：

Java Type
├── Primitive Type      基本类型
└── Reference Type      引用类型

其中引用类型进一步包括：

Reference Type
├── Class Type          类类型
├── Interface Type      接口类型
├── Type Variable       类型变量
└── Array Type          数组类型

此外，Java 语言中还存在一个特殊的：

null type

但它不是普通意义上可以声明变量的类型，也不应该简单地和基本类型、引用类型并列理解。

所以，真正严谨的结论是：

Java 固定只有 8 种基本类型；引用类型则没有固定数量，因此 Java 的所有具体类型不存在一个固定总数。

三、基本数据类型：固定只有 8 种

Java 的基本类型，也叫：

Primitive Type

它们不是对象，不属于类体系，也不继承 Object。

8 种基本类型如下：

分类 类型 位数 示例
整数 byte 8 byte a = 10;
整数 short 16 short b = 1000;
整数 int 32 int c = 100000;
整数 long 64 long d = 100L;
浮点 float 32 float e = 3.14F;
浮点 double 64 double f = 3.14;
字符 char 16 char g = 'A';
布尔 boolean JVM 规范不按普通整数位宽定义其存储实现 boolean h = true;

四、整数类型其实有 5 种

很多教程会说：

整数类型：
byte
short
int
long

从日常编程角度这样说没有问题。

但是从 Java 类型系统角度，char 也属于：

Integral Type

因此更加严谨的分类是：

Integral Type
├── byte
├── short
├── int
├── long
└── char

例如：

char c = 'A';

字符 'A' 对应 Unicode 编码值，因此 char 可以参与部分整数运算。

例如：

char c = 'A';

System.out.println((int) c);

输出：

65

所以 char 虽然通常用于表示字符，但从 Java 语言的类型分类来看，它属于整数类型体系。

五、浮点类型：float 与 double

Java 有两种浮点类型：

float
double

float

float price = 3.14F;

必须注意：

3.14

默认是 double。

因此赋值给 float 时通常需要：

3.14F

double

double pi = 3.1415926;

Java 浮点字面量默认就是 double。

在一般科学计算和普通业务计算中，double 使用更加广泛。

但是对于金融金额：

double money = 0.1 + 0.2;

可能出现浮点精度问题，因此通常会使用：

BigDecimal

注意：

BigDecimal

不是基本类型，而是一个类。

六、boolean：逻辑类型

Java 中只有一个布尔基本类型：

boolean

只有两个逻辑值：

true
false

例如：

boolean login = true;

if (login) {
    System.out.println("登录成功");
}

与 C 语言不同，Java 不允许直接把整数当作布尔值。

下面代码错误：

int a = 1;

if (a) {
}

Java 要求 if 条件必须最终产生布尔结果。

正确：

if (a != 0) {
}

十、接口类型：Interface Type

接口本身也是一种引用类型。

    @Override
    public void fly() {
        System.out.println("Flying...");
    }
}

可以：

Flyable bird = new Bird();

这里：

Flyable

就是接口类型。

Java 标准库中大量类型都是接口，例如：

List
Set
Map
Runnable
Comparable
Serializable
Collection

例如：

List<String> list = new ArrayList<>();

变量声明类型：

List<String>

属于接口类型。

对象实际类型：

ArrayList<String>

属于类类型。

这也是 Java 面向接口编程的重要基础。

从 Java 类型系统角度，可以把它理解为特殊的接口类型。

十二、数组也是引用类型

十五、参数化类型：Parameterized Type

例如：

都属于参数化后的泛型类型。

例如：

这里可以理解成：

        ↓

但是需要注意：

参数化类型并不是 Java 顶层类型分类中新增加的第三大类。

十六、Raw Type：原始类型

看下面两种写法：

List<String> list = new ArrayList<>();

以及：

List list = new ArrayList();

第二种没有提供泛型参数：

List

这叫：

Raw Type
原始类型

Raw Type 主要用于兼容 Java 5 引入泛型之前的旧代码。

现代 Java 开发中通常不建议使用。

因为它会失去泛型提供的编译期类型安全。

例如：

List list = new ArrayList();

list.add("Hello");
list.add(100);
list.add(new Student());

编译器很难提供严格的元素类型约束。

而：

List<String> list = new ArrayList<>();

只能正常添加字符串：

list.add("Hello");

下面会直接编译错误：

list.add(100);

十七、Wildcard：泛型通配符

Java 泛型中还有：

?
? extends T
? super T

例如：

List<?> list;

表示：

一个元素具体类型未知的 List。

再例如：

List<? extends Number>

表示：

List 中元素类型是 Number 或 Number 的某个子类型。

例如可能是：

List<Integer>
List<Double>
List<Long>

再例如：

List<? super Integer>

表示：

元素类型是 Integer 或 Integer 的某个父类型。

泛型中经常会提到：

PECS

即：

Producer Extends
Consumer Super

简单理解：

读取数据为主：
? extends T

写入数据为主：
? super T

这是 Java 泛型中非常重要的知识点。

十八、Intersection Type：交叉类型

Java 还存在：

Intersection Type

即：

A & B

表示一个类型必须同时满足多个约束。

例如：

<T extends Number & Comparable<T>>

其中：

Number & Comparable<T>

就是交叉类型结构。

意思是：

T 必须：

是 Number 的子类型

并且

实现 Comparable<T>

例如：

public static <T extends Number & Comparable<T>>
void print(T value) {

    System.out.println(value);
}

交叉类型还可能出现在强制类型转换中：

(Runnable & java.io.Serializable) () -> {
    System.out.println("Hello");
};

这里要求 Lambda 对象同时满足：

Runnable
+
Serializable

十九、null 是什么类型？

这是 Java 类型系统中很容易被忽略的一个特殊概念。

例如：

String name = null;

Student student = null;

Object object = null;

为什么 null 可以赋值给不同的引用类型？

因为 Java 语言中存在一个特殊的：

null type

它唯一对应的值就是：

null

但是不能写：

null value;

因为：

null

不是一个可以直接作为类型名称使用的关键字类型。

所以更加准确地说：

null 是空引用字面量，它具有一个特殊的 null type，并可以转换成引用类型。

二十二、String 到底是什么类型？

很多 Java 初学者会产生疑问：

String name = "LingXi";

看起来和：

非常像。

于是容易误认为：

String 的真实身份是：

↓
Class Type
↓
Reference Type

也就是说：

String 是 Java 提供的一个类。

只不过 Java 对字符串字面量提供了非常方便的语法：

所以使用体验看起来很像基本类型。

这句话也需要修正。

Object

所以：

并不继承：

例如：

这里 a 不是对象。

但是自动装箱之后：

此时：

↓

二十九、考试、面试应该怎么回答？

不同问题，要给不同层级的答案。

问：Java 有多少种基本数据类型？

回答：

Java 有 8 种基本数据类型：byte、short、int、long、float、double、char、boolean。

问：Java 数据类型分为哪两大类？

回答：

Java 类型主要分为基本类型和引用类型。

Primitive Type
Reference Type

问：Java 的引用类型有哪些？

回答：

Java 引用类型主要包括类类型、接口类型、类型变量和数组类型。

Class Type
Interface Type
Type Variable
Array Type

问：String 是基本类型吗？

回答：

不是。String 是 java.lang.String 类，因此属于引用类型中的类类型。

问：数组是基本类型还是引用类型？

回答：

数组属于引用类型。即使数组元素是 int，int[] 本身依然是引用类型。

问：Integer 是基本类型吗？

回答：

不是。Integer 是 int 对应的包装类，属于类类型。

问：void 是基本类型吗？

回答：

不是。void 用于表示方法没有返回值，不属于 Java 的 8 种基本类型。

问：var 是类型吗？

回答：

不是。var 是局部变量类型推断语法，变量最终仍然拥有具体的静态类型。

三十、最终总结

如果只记一句话：

Java 固定只有 8 种基本数据类型，但 Java 的所有具体类型没有固定总数量。

8 种基本类型：

byte
short
int
long
float
double
char
boolean

Java 类型体系最核心的结构：

Java Type
├── Primitive Type
└── Reference Type

引用类型主要包括：

Class Type
Interface Type
Type Variable
Array Type

除此之外，还应该理解：

Parameterized Type
Raw Type
Wildcard
Intersection Type
null type

最终真正需要建立的思维不是：

Java = 背 8 个数据类型

而是：

Java 类型系统
      │
      ├── 基本值
      │
      ├── 对象
      │
      ├── 接口抽象
      │
      ├── 数组
      │
      ├── 泛型
      │
      └── 编译器类型约束

当这套类型体系真正建立起来之后，后续学习：

面向对象
集合框架
泛型
反射
Lambda
Stream
Java API
Spring

都会更加自然。

因为它们本质上都建立在 Java 的类型系统之上。
