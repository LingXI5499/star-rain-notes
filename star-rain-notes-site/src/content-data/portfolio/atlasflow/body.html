项目介绍

把地图探索与影像浏览连接起来，让用户从“选择一个地方”自然过渡到“观看这个地方附近的影像”。核心工作集中在坐标到屏幕的转场、真实照片检索和多种输入方式的统一。

核心功能

使用流程

选择城市或点击地球 → 探索附近影像 → 观看照片浮现转场 → 浏览与放大照片 → 按需开启手势 → 返回原地球视角。

技术栈

关键实现

Vue 组件组织地图、照片墙、转场与手势面板；显式体验状态管理请求切换、分页和返回。照片服务通过 provider 接口隔离；MediaPipe Worker 串行推理，避免占用主线程和堆积视频帧。缩略图按需准备，地图与照片署名保持可见。

源码位于 AI Coding 作品集合的独立目录，运行方法与依赖以项目 README 为准。

当前阶段与使用边界

地图和照片需要外网；坐标附近可能没有足够的地理照片。手势需 HTTPS 或 localhost、摄像头和主动授权。风景优先属于排序规则，不是图像内容识别；没有用户账户或云相册。
