项目介绍

先验证 Blender 建模、FBX 导入、材质和场景组织，再在基础沙盒上加入具有目标的探索流程。当前作品用于展示资源管线、脚本分工和玩法原型，不作为已经发布的完整游戏。

核心功能

使用流程

用匹配版本的 Unity 打开工程 → 加载 MainScene → 进入 Play Mode 检查角色与场景 → 收集碎片并尝试激活祭坛 → 解锁传送门；按需使用关卡构建菜单，操作前保存当前场景。

技术栈

关键实现

玩法层由 Core、Player、Collectibles、Interaction、Environment 与 UI 脚本组成。事件驱动状态展示，编辑器构建工具组织场景内容。Assets、Packages、ProjectSettings 与 .meta 一起保留，Blender 源资产放在 art-source。

项目成果

验证与交付

2026-10-15 整理版本保留 12 个玩法脚本、主场景与 56 个资源 GUID，静态检查未发现因精简造成的本地引用缺失。已有基础沙盒的移动、跳跃与鼠标操作记录；新增完整玩法未在本次重新执行 Play Mode 或独立构建验收。

源码位于 AI Coding 作品集合的独立目录，运行方法与依赖以项目 README 为准。
