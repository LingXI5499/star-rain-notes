项目介绍

从一次请求出发，把容易混淆的网络、容器、框架、业务和数据库职责放进同一条可观察的链路。学习者既能看概念关系，也能修改 SQL 检查具体数据结果。

核心功能

使用流程

选择业务实验 → 对照 HTTP、Controller、Service、Mapper 和 SQL → 编辑执行 SQL → 检查结果与约束 → 切换运行机制节点 → 进入架构演示或演讲模式。

技术栈

关键实现

内容、视图与确定性教学模型分离；Three.js 负责球面与示意路径，SVG 展示关系和 Trace。CodeMirror 承载代码阅读与 SQL 编辑，SQLite WASM 在 Worker 中运行独立种子数据库。

项目成果

验证与交付

2026-10-15 整理版本通过 22 项测试与生产构建。全部 46 个 SQL 实验在新种子数据库中执行，包含 44 个正常执行和 2 个预期约束拒绝；测试核对分页、连接、关联写入和事务不变量。

源码位于 AI Coding 作品集合的独立目录，运行方法与依赖以项目 README 为准。

当前阶段与使用边界

项目本身是前端教学网站，不包含可运行 Spring Boot 服务，Java 片段只读。资源池、缓存、集群、队列和熔断属于明确简化的教学模型，不能据此推导真实生产容量或中间件性能。
