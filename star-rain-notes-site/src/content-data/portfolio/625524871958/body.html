项目介绍

星雨笔录是一个面向个人长期学习与知识沉淀的全栈知识平台。

项目并不只是展示文章的普通博客，而是围绕“内容组织、系统学习、持续维护和实际部署”建立的一套知识管理系统。平台将教程、英语学习、作品展示和后台内容管理放在统一架构中，让零散内容能够按照知识体系、课程目录和学习路径进行组织。

项目目标

星雨笔录主要解决以下问题：

  • 将分散的学习笔记整理成结构清晰的知识体系。
  • 使用教程、目录和章节组织长期学习内容。
  • 为英语阅读、听力、写作、词汇和语法学习提供统一入口。
  • 通过后台管理内容的创建、编辑、审核、发布和撤回。
  • 保存稳定的内容编号和公开地址，避免修改标题后链接失效。
  • 通过真实服务器部署验证项目的完整运行链路。

核心功能

系统化教程

教程模块按照“知识体系 → 教程 → 目录分组 → 章节”的层级组织内容。

管理员可以在后台创建知识体系和教程，并维护章节目录、Markdown 正文、摘要、排序和发布状态。学习者可以在前台按照知识体系浏览教程，通过目录进入具体章节。

这种结构适合组织 Java、计算机基础、开发工具、智能体开发和软件工程等需要长期维护的学习内容。

英语学习

英语模块用于组织不同类型的英语学习资料，目前包含：

  • 单词与词汇内容。
  • 词族及派生词学习。
  • 英语语法教程。
  • A1–C2 分级阅读。
  • 完整听力材料和逐句时间片段。
  • 语音规则学习。
  • 写作资源与写作任务。
  • 跨模块学习组合。
  • 学习记录与学习分析。

阅读、听力和写作内容可以按照 CEFR 等级及主题、文体、场景、能力和语言功能等标签分类。

听力模块采用“一份完整音频 + 完整听力稿 + 时间片段”的结构。每个时间片段记录对应的英文原文、中文翻译以及在音频中的开始和结束时间，从而支持逐句学习和定位。

内容管理

后台管理系统用于维护平台内容，包括：

  • 教程和章节管理。
  • 博客内容管理。
  • 作品管理。
  • 英语阅读、听力、写作和词族管理。
  • 媒体资源管理。
  • 内容审核与发布状态管理。
  • 用户、邀请和权限相关管理。
  • 学习数据与后台分析。

系统区分普通管理员和超级管理员的操作权限。内容可以经历草稿、发布和撤回等生命周期，降低误操作对公开内容的影响。

内容编号与稳定地址

具有独立访问地址的内容由后端自动生成 12 位数字编号。

修改标题时不会自动修改已有编号，因此公开地址能够保持稳定。数据库唯一约束同时作为并发情况下的最终保护。

学习记录

学习者登录后可以使用阅读、听力、写作等学习内容。系统能够保存相应的学习行为和练习结果，为个人学习记录、推荐和后台分析提供数据基础。

技术架构

后端

后端基于 Java 21 和 Spring Boot 3.5 构建，负责：

  • REST API。
  • 用户认证与权限校验。
  • 教程、英语和作品等业务逻辑。
  • 内容生命周期和审核流程。
  • 数据库访问与事务处理。
  • 媒体上传与访问地址管理。
  • 参数校验及统一错误响应。
  • 健康检查和生产环境配置。

MyBatis-Plus 用于数据库访问，MySQL 8 保存业务数据，Flyway 管理数据库结构版本。

前端

前端基于 Vue 3、TypeScript 和 Vite 构建，包含：

  • 面向访客和学习者的公开页面。
  • 教程与英语学习界面。
  • 登录和个人学习相关页面。
  • 面向管理员的内容管理控制台。
  • 响应式页面布局和主题展示。
  • 与后端 API 的统一请求和错误处理。

生产构建完成后，前端静态文件由 Nginx 提供访问。

部署

项目部署在阿里云服务器，并使用宝塔面板辅助维护。

生产环境主要链路为：

  1. 用户通过域名访问网站。
  2. Nginx 返回 Vue 构建后的静态资源。
  3. /api/ 请求由 Nginx 反向代理到 Spring Boot 服务。
  4. /uploads/ 用于访问上传的媒体资源。
  5. Spring Boot 连接 MySQL 数据库处理业务数据。
  6. 环境变量保存数据库连接、认证和媒体目录等生产配置。

前端、后端、数据库和上传文件相互独立，升级应用时可以保留原有业务数据与媒体资源。

项目特点

  • 教程内容采用多层级知识结构，而不是简单文章列表。
  • 英语模块覆盖阅读、听力、写作、词汇和语法等学习场景。
  • 后台提供内容创建、审核、发布、撤回和排序能力。
  • 内容编号由后端统一生成，公开地址保持稳定。
  • 数据库结构通过 Flyway 按版本维护。
  • 前后端采用分离架构，并完成真实服务器部署。
  • 应用升级时保留数据库、上传文件和既有内容。

当前状态

星雨笔录目前已经完成前后端构建和服务器部署，网站可以通过正式域名访问。

项目仍会随着实际学习和使用持续完善。后续工作将集中在充实高质量学习内容、优化管理流程、完善练习体验以及提高系统可靠性。
