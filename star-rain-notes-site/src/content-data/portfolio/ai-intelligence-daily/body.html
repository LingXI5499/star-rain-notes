项目介绍

用一个轻量网页代替在多个站点之间反复切换，围绕固定频率、可观察刷新和可降级摘要形成个人情报入口，而不是扩展成重型实时舆情系统。

核心功能

使用流程

打开首页查看最近日报 → 按需立即刷新 → 观察各来源进度 → 浏览去重后的信息与原始链接 → 查看摘要。服务持续运行时由每日定时任务触发相同流程。

技术栈

关键实现

FastAPI 提供页面与刷新 API，Jinja2 渲染首页。Collector 与刷新服务分离，自动与手动刷新共享同一任务锁；SQLite 使用指纹去重和 WAL。摘要服务把外部模型调用与无 Key 的规则回退隔离。

项目成果

验证与交付

2026-10-15 整理版本通过 13 项自动测试，覆盖数据库去重、模型指纹、采集解析器、任务互斥、日报落库和每日调度边界。测试不代表外部来源在任何时间均可采集。

源码位于 AI Coding 作品集合的独立目录，运行方法与依赖以项目 README 为准。

当前阶段与使用边界

需要服务持续运行才能定时刷新。来源页面结构、网络和模型服务可能变化，采集失败保留最近数据。仅访问公开信息，没有登录绕过、验证码规避或私人数据采集。
