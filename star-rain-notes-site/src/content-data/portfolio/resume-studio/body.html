项目介绍

面向个人投递简历时频繁调整内容、管理多个版本和检查打印结果的需求，建立从编辑、保存、校验到 PDF 输出的完整本地流程。公开源码使用虚构演示资料和中性头像。

核心功能

使用流程

复制岗位版本 → 修改简历内容 → 检查 A4 预览和溢出提示 → 等待保存完成 → 导出 PDF → 定期备份 JSON。超页时在副本中人工精简内容。

技术栈

关键实现

Vue 编辑器与打印页复用 ResumeSheet，避免两套排版偏差。IndexedDB 保存版本与修订信息，BroadcastChannel 提醒多标签冲突。仅监听回环地址的 Express 服务使用独立数据快照生成 PDF，并校验来源、图片、字体和输出页数。

项目成果

验证与交付

2026-10-15 整理版本通过 16 项单元测试、类型检查和生产构建。3 个浏览器场景验证初始预览、单页中文 PDF、断开外网后的编辑与导出；生产模式也实际输出一页可检索中文的 PDF，未记录页面脚本错误。

源码位于 AI Coding 作品集合的独立目录，运行方法与依赖以项目 README 为准。

当前阶段与使用边界

需要本地 Node 服务、Chromium 与中文字体，不能只上传静态 dist 获得 PDF 能力。清理浏览器数据可能丢失本地版本，应独立备份。没有云账户、自动改写经历或任意模板设计；超页不裁切、不暗中删改经历。
