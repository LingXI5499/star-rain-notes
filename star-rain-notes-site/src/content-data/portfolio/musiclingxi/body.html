项目介绍

将简洁的个人离线播放需求落实成可构建的 Android 工程，重点处理播放顺序、Web 与原生适配器分工，以及离开 WebView 后的媒体控制。

核心功能

使用流程

安装依赖 → 在浏览器预览界面 → 自行导入本地音频并校验清单 → 按需放入歌词 → 同步 Android 资源与插件 → 构建 APK 并在真机检查后台播放。

技术栈

关键实现

业务界面使用 ES modules 与原生 CSS；统一播放服务在浏览器 HTMLAudioElement 和 Android 原生适配器之间选择。播放模式纯函数与共享顺序游标负责重复、随机和上一首历史，避免两个适配器同时发声。

项目成果

验证与交付

2026-10-15 整理版本通过 43 项测试、77 首占位清单资源检查、无歌词降级检查、Web 生产构建及 Android 插件/资源同步。此轮不代表所有 Android 真机与系统版本均已完成体验验收。

源码位于 AI Coding 作品集合的独立目录，运行方法与依赖以项目 README 为准。

当前阶段与使用边界

公开仓库只有 77 个零字节音频占位文件，不含真实音频及歌词正文，克隆后会显示“暂无音频 / 暂无歌词”。需要自行提供可使用的音频。没有联网曲库、账号、推荐或云同步。
