项目介绍

探索一个把“设定目标—安排今日行动—持续专注—记录习惯—复盘调整”连接起来的成长工作台。原型用于展示产品流程与交互设计，不把页面数量等同于服务端系统已完成。

核心功能

使用流程

建立目标或应用成长模板 → 选择效率方法生成行动 → 确认日程 → 专注与习惯打卡 → 查看趋势、积分和复盘 → 通过全局伙伴调整下一步。

技术栈

关键实现

Vue 页面与共享组件承载 18 个产品页面；Pinia 维护统一业务状态，domain 层负责校验、统计和规则。计划建议具有确认、过期检查和冲突保护，撤销避免覆盖后续操作；数据保存于当前浏览器。

项目成果

验证与交付

2026-10-15 整理版本通过 38 项业务测试、TypeScript 检查和生产构建。原项目 v0.4 验证记录包含 34 个桌面与手机浏览器场景。

源码位于 AI Coding 作品集合的独立目录，运行方法与依赖以项目 README 为准。

当前阶段与使用边界

当前仍是前端原型：成长伙伴没有接入开放大模型；账户、社区、消息、会员和支付没有真实服务端。提醒仅在应用打开时显示，数据不跨设备同步。示例用户、榜单和社区内容明确属于演示。
