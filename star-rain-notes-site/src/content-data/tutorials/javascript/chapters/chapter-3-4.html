核心： 冒泡排序反复比较相邻元素并交换；一趟没有交换即可提前结束。

最小示例：

const a = [3, 1, 2];
for (let i = 0; i < a.length - 1; i++) {
  let changed = false;
  for (let j = 0; j < a.length - 1 - i; j++) if (a[j] > a[j + 1]) { [a[j], a[j + 1]] = [a[j + 1], a[j]]; changed = true; }
  if (!changed) break;
}
console.log(a);

学完能做： 用比较交换实现基础排序并提前退出。
