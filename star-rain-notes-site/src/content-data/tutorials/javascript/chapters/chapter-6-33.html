核心： Blob 创建文本文件数据，临时对象 URL 和 <a download> 触发浏览器下载。

最小示例：

const url = URL.createObjectURL(new Blob(['你好'], { type: 'text/plain;charset=utf-8' }));
const a = document.createElement('a');
a.href = url; a.download = 'note.txt'; a.click();
setTimeout(() => URL.revokeObjectURL(url), 1000);

学完能做： 在浏览器端创建并下载文本文件。
