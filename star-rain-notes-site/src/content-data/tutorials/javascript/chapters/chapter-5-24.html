核心： 滚动导航可读取位置，点击目录时用 scrollIntoView，回顶部用 scrollTo。

最小示例：

document.querySelector('#toTop').onclick = () => window.scrollTo({ top: 0, behavior: 'smooth' });
document.querySelector('#part2').onclick = () => document.querySelector('#section2').scrollIntoView({ behavior: 'smooth' });
