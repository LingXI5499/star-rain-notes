核心： 拖放排序从 dragstart 保存被拖元素，到 drop 时移动节点或重排数组。

最小示例：

let dragging;
list.addEventListener('dragstart', e => dragging = e.target.closest('li'));
list.addEventListener('dragover', e => e.preventDefault());
list.addEventListener('drop', e => { e.preventDefault(); const li = e.target.closest('li'); if (li && li !== dragging) li.before(dragging); });

学完能做： 在拖放后更新元素或数据顺序。
