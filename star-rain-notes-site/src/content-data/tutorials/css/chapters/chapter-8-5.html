核心： 父容器设置 overflow:hidden，左右门板通过 translateX 分开形成双开门效果。

最小示例：

.door { display: flex; overflow: hidden; }
.door > div { flex: 1; transition: transform .4s; }
.door:hover > :first-child { transform: translateX(-100%); }
.door:hover > :last-child { transform: translateX(100%); }

学完能做： 结合裁切和平移制作双开门效果。
