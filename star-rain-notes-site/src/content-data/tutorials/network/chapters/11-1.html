网络原理综合实践

  • 实践一：完整请求链路。 记录浏览器访问 HTTPS 站点时 DNS、TCP、TLS、HTTP、缓存与服务端入口的过程。
  • 实践二：TCP Echo 服务。 分别使用 Java 和 Python 实现客户端与服务端，验证连接建立、数据收发和连接关闭。
  • 实践三：应用层消息协议。 为 TCP 通信实现长度前缀协议，测试部分读取、消息拼接、非法长度与连接中断。
  • 实践四：HTTP API 调用器。 使用 Java 和 Python 调用 HTTP API，实现超时、错误分类、JSON 校验、有限重试与日志。
  • 实践五：网络故障排查。 使用 DNS 工具、`curl`、端口检查、浏览器 Network 面板及抓包工具定位模拟故障。
  • 实践六：连接与性能观察。 比较串行、线程池和异步请求的延迟、吞吐量与资源使用。
  • 实践七：TLS 验证。 观察证书链、域名不匹配、过期证书和系统时间异常导致的连接失败。
  • 实践八：故障报告。 每次实验记录现象、环境、复现步骤、证据、根因、修复与复验结果。
