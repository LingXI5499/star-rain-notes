端口、传输层与 TCP/UDP 基础

  • 端口的作用：将到达主机的数据交给相应网络服务。
  • IP、端口、传输层协议与网络端点的关系。
  • TCP/UDP 五元组：源 IP、源端口、目的 IP、目的端口、传输层协议。
  • 常见端口约定：DNS 53、HTTP 80、HTTPS 443、SSH 22；端口号不保证对应服务一定运行。
  • TCP 的特点：面向连接、可靠、有序、字节流。
  • UDP 的特点：无连接、保留数据报边界、开销较低，但不保证送达和顺序。
  • TCP 与 UDP 的适用场景和取舍。
  • 同一主机上 TCP 与 UDP 可以使用相同的端口号。
  • Socket 的基本概念：应用程序使用网络协议进行通信的编程接口。
