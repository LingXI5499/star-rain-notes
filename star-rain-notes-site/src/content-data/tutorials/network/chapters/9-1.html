Java TCP、UDP 与 Socket API

  • `InetAddress`、`InetSocketAddress`：地址与域名解析。
  • `Socket`、`ServerSocket`：TCP 客户端和服务端。
  • `DatagramSocket`、`DatagramPacket`：UDP 数据报。
  • `InputStream`、`OutputStream`、字节流与字符编码。
  • `connect()` 超时、`SO_TIMEOUT` 读取超时及其他常见 Socket 选项。
  • `SO_KEEPALIVE`、`TCP_NODELAY` 的作用与适用场景。
  • try-with-resources、连接关闭顺序、异常处理与资源释放。
  • 使用 Java 实现定长、分隔符或长度前缀消息协议。
  • 处理部分读取、连接断开、超时和服务端并发连接。
