HTTP 基础与报文结构

  • HTTP 的客户端---服务端模型、请求---响应模式与无状态特征。
  • URL/URI 的组成：协议、主机、端口、路径、查询参数与片段。
  • 请求行、状态行、请求头、响应头与消息体。
  • HTTP/1.1 的消息长度与边界：`Content-Length`、`Transfer-Encoding` 和分块传输。
  • `Content-Type` 与 `Accept` 的区别；媒体类型、字符编码与 JSON。
  • 常见请求头：`Host`、`Authorization`、`Cookie`、`Accept`、`Content-Type`。
  • 常见响应头：`Cache-Control`、`ETag`、`Last-Modified`、`Location`、`Set-Cookie`。
  • 压缩、重定向、范围请求、文件上传与下载。
  • HTTP 请求与 TCP 连接的区别：TCP 建连成功不代表 HTTP 业务请求成功。
