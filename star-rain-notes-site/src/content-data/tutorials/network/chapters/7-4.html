网络工具与分层故障排查

  • 分层排查顺序：DNS → IP/路由 → TCP → TLS → HTTP → 应用业务。
  • `ping`、`traceroute` / `tracert`：连通性与路径诊断及其局限。
  • `nslookup`、`dig`、`Resolve-DnsName`：检查域名解析。
  • `ipconfig`、`ip addr`、`ip route`：检查本机地址和路由。
  • `ss`、`netstat`、`Get-NetTCPConnection`：查看监听端口与连接状态。
  • `curl -v`、`curl -I`、连接超时与总超时参数。
  • `openssl s_client`：检查 TLS 握手、证书链与 SNI。
  • Wireshark、tcpdump：过滤报文，观察握手、重传、关闭与异常流量。
  • 浏览器 Network 面板：定位 DNS、连接、TLS、等待响应和下载耗时。
  • 区分连接拒绝、超时、连接重置、对端关闭、TLS 错误与 HTTP 错误。
  • Windows 与 Linux 下的常用排查命令。
