Java HTTP 客户端与 REST API 调用

  • JDK `java.net.http.HttpClient`、`HttpRequest`、`HttpResponse`。
  • GET/POST、请求头、请求体、状态码、响应体与 JSON 解析。
  • 同步 `send()`、异步 `sendAsync()` 与 `CompletableFuture`。
  • 连接超时与请求超时的区别；请求超时不等于所有底层阶段使用同一个计时器。
  • 连接复用、重定向策略、代理、TLS 配置与异常处理。
  • 复用 HTTP 客户端实例、并发调用、资源生命周期与有限重试。
  • 在 Spring 项目中认识 `RestClient`、`WebClient` 与 `RestTemplate` 的定位。
  • 根据同步/异步需求、Spring 版本和项目现状选择客户端，而不是机械追新。
  • 外部 API 调用的超时、错误响应、幂等、日志脱敏与可观测性。
