TCP 可靠传输、流量控制与拥塞控制

  • 序列号、确认号、按序交付、重复数据识别与确认机制。
  • 超时重传、快速重传、累计确认与选择性确认（SACK）的基本思想。
  • 滑动窗口、接收窗口、发送窗口与零窗口。
  • 流量控制：避免发送方超过接收方处理能力。
  • 拥塞控制：慢启动、拥塞避免、快重传、快恢复的基本思想。
  • RTT、重传超时（RTO）、延迟确认与传输效率。
  • 经典拥塞控制算法与现代实现（如 CUBIC、BBR）的基本认知。
  • TCP Keepalive 与 HTTP Keep-Alive 的区别。
  • TCP 可靠性只保证传输层字节流的交付，不保证业务事务已成功执行。
