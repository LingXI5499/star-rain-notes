HTTPS、TLS 与数字证书

  • HTTP 的安全风险：窃听、篡改、冒充与中间人攻击。
  • TLS 的目标：机密性、完整性与身份认证。
  • 对称加密、非对称加密、哈希、消息认证码与数字签名的职责。
  • 数字证书、CA、证书链、信任根、有效期、用途与域名匹配。
  • TLS 握手：协商参数、验证身份、建立会话密钥。
  • TLS 1.2 与 TLS 1.3 的主要差异；避免将某个版本的握手过程当作所有版本的统一流程。
  • SNI 与 ALPN 的作用。
  • 单向 TLS 与双向 TLS（mTLS）的基本用途。
  • HTTPS 中 HTTP、TLS 与 TCP 的关系；HTTP/3 使用 QUIC 并集成 TLS 1.3。
  • 证书过期、域名不匹配、证书链不完整、系统时间错误等常见故障。
  • 证书验证、主机名验证与信任库；为什么不能随意关闭证书验证。
  • TLS 1.3 早期数据（0-RTT）的重放风险与业务使用边界。
