  • 数据发送时的封装、接收时的解封装，以及各层头部的作用。
  • 输入 URL 后的主要步骤：解析 URL、检查缓存、DNS 解析、选择路由、建立传输连接、TLS 握手、发送 HTTP 请求、服务端处理、返回响应。
