组成： 文档类型声明、根元素、文档头部、元信息、页面标题、页面主体。

最小示例：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>欢迎</h1>
  <p>第一个 HTML 页面</p>
</body>
</html>

学完能做： 独立编写 HTML5 文档骨架并在浏览器打开。
