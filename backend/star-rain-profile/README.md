# 作者资料模块

`star-rain-profile` 管理站点作者介绍。公开接口 `GET /api/public/profile` 返回作者简介、经历、技能、社交链接和可展示的精选内容；后台 `/api/admin/profile` 只允许超级管理员编辑。

数据库迁移为 `V2_013__profile.sql`，初始资料仅填入站点名称，其他个人信息由管理员维护。经历、技能、社交链接和精选内容分别保存，支持排序与移除。头像与简历关联媒体库资产，头像限公开图片，简历限公开 PDF；更换时同步维护媒体引用。

精选内容通过博客、教程、作品各模块的公开 API 校验，公开读取时再次检查目标状态，已撤回或下架的内容不会展示。教程标题与摘要取已发布快照，避免未发布的编辑内容泄漏。资料变化在事务提交后发布 `ProfileChangedEvent`。
