## 数据库迁移

新增 `V2_038__tutorial_workspace_versions.sql`，为章节、知识卡片、章节问题添加非空 `row_version BIGINT DEFAULT 0`。不修改既有迁移，不重写 Revision，不删除学习数据。

## 发布与并发约束

1. 工作区与公开 Revision 分离；所有写操作先锁定所属教程，审核中暂不接受修改。
2. 章节保存携带读取时的 rowVersion；SQL 条件更新并递增，旧版本或缺少版本返回 409。
3. 单章发布/撤回在事务内复制当前公开 Revision，只替换/移除目标章节；其余章节与教程元信息保留原快照。首次发布单章只包含该章。
4. 普通编辑者提交不可变候选 Revision 至现有 review 模块；批准前不切换公开版本。
5. 版本切换提交后发布现有 TutorialPublicationChangedEvent，刷新 Search、SEO；新增 Revision 挂接媒体引用，旧 Revision 引用保留。
6. 撤回不执行删除或学习清理；历史计划、证据、答案继续保留。

### 根因与修复

1. `editableTutorial` 错用公开状态锁死工作区，现仅审核中锁定编辑，公开读取始终取不可变 Revision。
2. 原章节撤回/公开只更新工作区状态，且只要求编辑权限。现发布要求 `tutorial:publish`，撤回要求 `tutorial:withdraw`，普通编辑者以 `tutorial:submit` 进入现有审核流程。单章操作在事务内复制当前公开快照，仅变更目标章节。
3. 原前端先保存标题摘要再保存正文，两次事务可能部分成功。现一次请求携带 `rowVersion`，条件 SQL 同时保存标题、摘要、正文与版本，媒体引用失败也回滚。
4. 原预览只查询 PUBLISHED 章节。工作区预览查询全部章节，包括草稿与撤回内容。
5. 原卡片、问题未统一校验教程审核状态且没有并发版本检查。现与正文共同锁所属教程、使用条件 SQL 更新，所有子内容修改也推进章节版本。
6. 原课程结构整行双击冒泡容易误跳转，且同组件参数变化不重载。现保留明确的正文/卡片/问题按钮，移除整行双击跳转并监听路由参数。
7. 教程排序原本整行写回，可能覆盖公开版本指针。现只写排序字段。
8. 审核结论由 afterCommit 回调执行，教程回调使用 `REQUIRES_NEW` 确保公开切换独立提交。
9. 新 Revision 登记正文、卡片背面、问题参考答案的媒体引用；工作区媒体引用包含停用内容，旧 Revision 引用保持。
10. 存在历史 Revision 的教程/章节禁止永久删除，使用撤回保留学习关联。撤回不调用学习清理、不删除当前内容行或历史 Revision。

### 实际修改范围

生产逻辑仅位于 `star-rain-v2`。Controller、Service、Mapper、XML 分层保持，未修改旧根目录 frontend/backend。新增四类内容版本 DTO/Entity/VO 字段、新 Flyway 迁移、审核提交入口，以及上述前后端测试。Search/SEO 沿用当前公开 Revision 的来源与提交后事件机制，并新增回归测试。Maven reactor 与前端包版本统一为 2.0.1。

### 部署步骤（人工验收通过并合并 PR 后）

1. 宝塔 → 数据库 → `star` → 备份；备份服务器现有 `app.jar`、`dist` 和 `application-prod.yml`。
2. 宝塔 → 网站 → Java 项目 → 当前项目 → 服务 → 停止。
3. 将交付包 `app.jar` 上传覆盖 `/www/wwwroot/star-rain-v2/app.jar`。解压 `dist.zip` 到 `/www/wwwroot/star-rain-v2`，结果应为 `dist/index.html` 与 `dist/assets`。
4. 前端采用覆盖上传，**保留现有 media 目录和媒体文件**；尤其现有媒体若放在 `dist/media`，不要删除整个 dist。无需上传任何本机密钥配置。
5. 沿用现有启动命令、JDK 21、18088 端口、生产 yml 和 Nginx 配置。启动项目后 Flyway 自动新增 V2_038 的三个版本字段；无需重新导入业务 SQL。
6. 查看 Java 日志确认启动成功、Flyway 最新版本 2.038。浏览器强制刷新，依次验证编辑保存、单章发布、单章撤回、卡片问题、学习历史和搜索。
7. 数据库迁移是新增字段；如需回退应用，可恢复旧 jar 和前端，保留新增字段，**不要手工删除 Flyway 历史或回退旧迁移文件**。

### 范围与剩余风险

- 生产服务器为 MySQL 8.4，本机自动化验证为 MySQL 8.0；迁移仅使用兼容的 ADD COLUMN，仍需人工按以上流程验收生产配置。
- 审核中锁定工作区，完成或取消审核后继续编辑；单章发布不自动发布教程标题、分组名、排序或其他章节草稿。发布全部改动需使用教程级入口。
- 历史教程不提供永久删除入口，保留学习证据与旧公开版本；撤回最后一个章节后教程公开目录可为空。
- Search/SEO 使用现有提交后刷新机制。若事件消费遇到基础设施故障，检查日志并通过后台重建派生索引；未引入新的缓存系统。
- 已提交任务只创建 PR，等待人工验收合并；没有执行生产部署、生产数据修改或 main 合并。
