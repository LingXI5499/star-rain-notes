# 访问统计模块

`star-rain-analytics` 记录受控公开页面访问，以及博客、教程章节和作品详情成功读取后的内容访问。公开入口只接受白名单路由；内容 ID 由业务服务端传入，浏览器不能上报任意内容热度。记录写入异常只记日志，不影响公开内容读取。

原始事件只保存路由模板、内容类型和 ID、来源类别与来源主机名。数据库不保存 IP、完整 User-Agent 或来源 URL 的路径与查询参数。来源分布只统计有来源信息的页面访问，不把服务端内容读取误算为直接访问。公开记录入口使用进程内随机盐对来源地址做短期限流。每天 UTC 02:15 重算前 3 天聚合，重跑按日期替换；原始事件默认保留 90 天，聚合长期保留。

后台 `/api/admin/analytics` 提供汇总、趋势、内容热度和来源分布，仅超级管理员持有 `analytics:read` 可访问。统计日期以 UTC 为准，查询跨度最多 366 天。数据库迁移为 `V2_014__analytics.sql`。
