# 版本记录

## v2.0.0 · 2026-10-09

星雨笔录 V2 首个正式源码版本。V2 集成分支为 `mainV2`，正式发布分支为 GitHub 默认分支 `main`。

- 采用 Vue 3 与 Spring Boot 多模块结构，独立维护 V2 数据库、会话和迁移。
- 提供账户激活、管理员邀请、固定角色权限、内容管理和媒体库。
- 完成教程目录、章节、问题与练习，以及学习记录、掌握度、复习和学习计划。
- 完成博客主题与标签、时间线、阅读界面与公开主题 SEO。
- 完成作品内容区块、展示模板和隔离运行的多页面静态原型。
- 完成英语词汇、发音、学习计划、语法、双语阅读和私有写作；支持按权限公开管理员原创文章。
- 全站搜索与快捷搜索覆盖英语词汇、语法、阅读和公开原创写作，支持英语筛选、内容变更同步与已有内容补建索引。
- 统一公开页面筛选、分页、昼夜主题与公开路径／账户路径，并补齐隐私及服务说明页面。
- 数据库迁移至 `2.037`，移除旧听力模块、阅读等级和旧写作数据模型。

源码版本不包含数据库内容、上传媒体、本地密钥、运行日志和内部交接材料。V1 源码与既有标签保留，V2 从 `star-rain-v2/` 构建和运行。

发布验证：后端 757 项测试通过（跳过 0 项）；前端 42 个测试文件、191 项测试通过。
