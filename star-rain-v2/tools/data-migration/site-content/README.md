# V1 作品与作者内容迁移

在已备份的 V2 数据库上手动执行 `Import-V1SiteContent.ps1 -TargetDatabase star_rain_v2`。
脚本将 V1 公开作品的正文、技术栈、项目阶段和链接导入 V2，并将 V1 作者资料、当前关注、GitHub、邮箱和精选作品填充到 V2。重复运行不会覆盖现有作品或手工修改的作者正文。

V1 的作品封面和截图指向媒体 ID 12、13、14、15、17；本机 V1 `backend/uploads` 中没有这些文件。脚本不会把失效媒体 ID 映射到 V2，也不会制造可访问的假封面。取得对应原文件后再单独导入 V2 媒体库并关联作品。
